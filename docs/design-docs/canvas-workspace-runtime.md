# 画布主工作区：本地实现

状态：2026-10-20，默认桌面入口已从股票页改成 Canvas。此前单独 Learn 页面只验证了交互协议，没有落实用户确认的画布主界面；现在 Note / Block / Placement 与交互块接在同一画布中。

## 已实现的体验

- 主区域为可平移、缩放的世界坐标画布；空格拖动或使用平移工具，空白左键拖动框选，滚轮平移，⌘ / Ctrl + 滚轮在指针处缩放；底部有缩放、100% 与适应内容。
- 双击空白处或点工具栏新建笔记。标题栏空白处或左侧图标用于拖动；每个框的四条边与四个角都可拖动调整宽高，上 / 左侧缩放固定对侧边。选中时显示蓝色矩形选框、四个白底蓝边角点，控制层独立浮在内容和形状上方；四边保留透明拖动热区；上 / 下为 ns-resize、左 / 右为 ew-resize、两组斜角分别为 nwse / nesw-resize，显式覆盖共享按钮的 pointer 光标。角点和命中范围按缩放保持屏幕尺寸；选中对象临时置于上层，避免被重叠卡片挡住手柄。
- 一篇笔记有可选标题和有序内容块；新建文本默认空标题，直接在顶部原位置填写、改名或清空，不在正文中重复显示标题编辑器。空标题静止时不显示替代标题，选中 / 悬停时提供「添加标题」入口。弹窗标题也在其顶部原位编辑。支持 Markdown / GFM 与行内、展示 LaTeX，双击正文默认在当前位置编辑 Markdown / LaTeX 源码并自动聚焦；点击卡片外部、键盘将焦点移出卡片或点标题栏「完成」后恢复渲染。同一卡片内切换标题、正文、插入控件不退出编辑。标题栏放大图标进入不受画布缩放影响的弹窗，源码与渲染结果实时并排预览，关闭后回到画布。当前使用原生 textarea，不声称已经接入完整富文本或虚拟化长文编辑器。
- 图片 / 文件可选择、拖入画布或笔记；图片也可粘贴进笔记，普通文本可粘贴成新笔记。附件原件存 IndexedDB，文档只存随机 ID、长度、摘要、MIME 和引用；下载保留原始字节。
- 同一内容可复制摆放；移出画布只删除那个 Placement，内容仍可从左上内容列表放回。撤销 / 重做作用于文档修改，输入中的同一文本块合并为一组。
- 温度探索器作为真正的 InteractiveBlock 放在画布上，也能插入笔记。控件操作不移动画布；个人参数按本机 profile / document / block / program 范围存储，同一块的多个摆放共享参数。
- 工具栏提供 26 个语义形状与可选 shapeStyle，形状 / 多选浮动栏详见 [选择与布局](canvas-selection-and-layout.md)；图形几何铺满摆放边界，矩形采用直角，选框描边与图形边界共线、四角锚点中心与顶点重合，避免图形内缩造成空隙；双击编辑形状文字，拖动形状本体移动；对象属性可置顶 / 置底。方向键按世界坐标微移 1，Shift + 方向键微移 10，⌘ / Ctrl + D 创建独立内容副本。
- 工具栏吸附默认开启：移动时与视口内其他对象的边缘 / 中心对齐，6 个屏幕像素内吸附并显示参考线；Alt 临时绕过，Shift 锁定移动轴。参考线与未提交几何只是视图状态。
- 选中对象即显示四侧浅蓝圆形连接点，可直接拖出箭头，无需切换工具；拖动期间显示其他对象的连接点，松手可绑定到对应侧边。圆点与形状留出屏幕固定间距，命中区大于可见圆点，独立于边缘缩放热区；连接工具与对象连接按钮仍可使用。选中线下方显示浮动栏，可选择圆角 / 直角折线 / 直线 / 曲线、实线 / 虚线 / 点线、14 种端点标记、粗细 / 颜色 / 透明度 / 跳线和文字格式。靠近目标时锚点贴到边界，吸附点实心高亮；端点可改接或脱离为自由坐标，中间线段可拖动。更多菜单支持复制 / PNG / 副本 / 样式 / 层级 / 旋转 / 锁定 / 删除，详见 [连线编辑](connector-editing.md)。移动 / 缩放及自动高度变化时连接跟随真实框边界。Escape / pointer cancel 放弃未完成连接。
- 右上文档 DSL 支持严格 JSON IR 编辑、校验应用和结构快照导出；无效内容不替换当前文档。**结构快照不包含附件原件或个人学习参数，不是完整的可移植备份包。**

浅深色和窄屏继续使用成熟桌面外壳；窄屏保持画布坐标，通过平移 / 缩放与聚焦编辑查看，不强行改写空间排布。Learn 保留为独立协议实验室，Canvas 才是默认工作区。

## 内容类型体验区

右上「体验样例」向当前文档追加 11 个可操作样例，左下「上一个 / 下一个」和下拉菜单逐项定位：Markdown 长笔记（标题、列表、表格、代码与待办）、LaTeX（行内 / 展示公式、矩阵与多行推导）、PNG 图片原件、文本附件、PDF 附件、温度交互学习块、混排长笔记，同一笔记的另一处摆放，以及矩形 / 菱形 / 椭圆和两条带标签的实线 / 虚线箭头（09–11）。PDF 当前是可下载的真实原件，尚无内嵌 PDF 阅读 / 编辑器；手写尚未实现，不提供占位演示。

样例使用现有文档命令一次追加，可撤销；PNG / TXT / PDF 字节与文档在同一 IndexedDB 事务保存，不依赖网络。体验区放在已有内容右侧，不改动已有正文、位置和学习参数。稳定 ID 使重复点击只补回缺少的摆放 / 示例连接，保留已编辑的样例；混排笔记复用独立示例的图片、文件和交互块，第 01 / 08 项共享同一篇笔记。定位只改变视口与选区。

## 文档内核与边界

`packages/core/src/canvas/document.ts` 实现 `nomi-document-ir/draft-1`：

| 对象 | 内容 |
| --- | --- |
| Document | ID、标题、本机 revision、notes、blocks、assets、board |
| Note | ID、可选标题（当前 JSON 字段为空字符串表示无标题）、有序 Block ID 列表、可选 parentId（文稿层级） |
| Block | Markdown 原文、未求值 InteractiveProgram、image / file 的 Asset 引用，或 shape 的形状 / 文字 / 色调枚举与可选格式 |
| Placement | ID、内容 ID、世界坐标 x / y、逻辑宽度、可选逻辑高度；省略高度表示内容自动高度，可选 group / locked，顺序是原始叠放顺序 |
| Connector | ID、绑定 Placement / side / 可选归一化 anchor 或自由 point / side 端点，routing、线型、起终标记、颜色 / 透明度 / 粗细、折点 / 跳线、文字格式、锁定 / 层级；属于 Board，不是 Note 正文 |
| Asset | ID、原始文件名、MIME、字节数、SHA-256、可选图片尺寸 |

`applyCanvasCommands` 在校验基准 revision 后原子提交创建笔记、改正文 / 标题、添加块、移动、调宽高、复制 / 删除 / 新增摆放、层级、形状和连接修改。中途失败不修改原文档；引用、唯一 ID、必需类型、交互能力、数值与预算均检查。Undo / Redo 恢复语义内容但产生新的 revision，避免旧写入重新变得有效。

文稿层级使用可选 `Note.parentId`，省略表示根级，旧文档保持平铺不改写；父文稿必须存在且不能循环。`move_note` 原子修改父关系与同级顺序，可移回根级，不能移入自身 / 后代；`delete_note` 同时删除后代、相关摆放及连线，仅清理不再被外部引用的所属块。页面层级不自动创建画布摆放或连接。单页归档去除父引用，不包含祖先 / 子页。完整体验见 [文稿层级](notes-authoring.md)。

连接绑定到摆放，而非内容：同一笔记的多个摆放可拥有不同关系。删除摆放在同一事务删除其关联连接，Undo 恢复两者；卡片复制摆放不自动复制连接；选区复制 / 独立副本会重新映射内部连接。允许旧文档省略 `board.connectors`，新增连接有最多 400 条、标签 200 字、有效端点 / 枚举 / 唯一 ID 约束，不接受悬空端点、自连接或任意样式字符串。当前运行时理解旧 draft-1，旧客户端可能拒绝新增字段；不声称跨版本双向兼容。

摄像机与选区不进入文档；世界坐标不依赖设备像素或 Retina scale。结构与内容都保留稳定 ID，拖动不改 Markdown；同一 Note 的多个摆放读同一 Block，不保存两份可互相覆盖的正文。

限制：文档 JSON 2 MiB，100 篇笔记、200 个块 / 摆放、64 个附件，每个 Markdown 块最多 200,000 字符；单个附件 20 MiB，图片边长最多 32,768 且总像素最多 64M；世界坐标 ±1,000,000，形状最小 16×16，其他内容框宽度 160–1,600、可选高度 120–2,400，形状沿用相同上限，缩放 20%–250%。交互块继续服从自身更严格的能力和预算。

这是一份已运行的文档语义 IR，不是 `document.nomi` / KDL parser 已经实现的声明。既有文件化格式样例仍是候选格式；KDL 前端及完整 source / asset 包需要独立往返验证。没有引入 CRDT，本机递增 revision 不能当作跨端因果版本。

## 存储与失败行为

`packages/platform/src/canvas.ts` 使用 `nomi.canvas.v1` IndexedDB：documents 和 assets 两个 object stores，key 包含本机 profile 与 document ID。附件字节和文档引用在同一事务提交；摘要、长度和不可变原件检查失败会 abort。写入检查已保存基准 revision，拒绝另一个旧页面覆盖新版本。

React 只维护一个语义副本，序列化提交并合并等待中的最新修改；界面在事务完成后才显示“已保存到本机”。配额或磁盘失败保留内存修改与待写原件（包括失败后撤销再重做的附件），显示“尚未保存”和重试。损坏 / 未来版本文档报错并保留原始存储，不回退后自动写入示例覆盖它。

摄像机在 `nomi.canvas.camera.v1:[profile,documentId]` 中单独保存；交互参数沿用独立学习状态存储，增加 document / block 实例范围。profile 是本机组织键，不是服务端身份或授权；没有家庭共享或云同步。移出摆放和 Undo 可能保留尚可恢复的内容 / 原件，GC、回收站与彻底删除尚未实现。

## 输入与预览约束

图片按 PNG / JPEG / GIF / WebP 文件头识别并解码；SVG、HTML 等保留为可下载文件，不当图片执行。加载原件再次校验 SHA-256 与长度；缺少附件显示占位，不猜测外部路径。图片块可保存独立 caption；PDF 用本机 PDF.js worker 分页预览，小文本可纯文本预览，失败或未知格式保留下载卡片。CSP 允许图片 blob、本地 / blob worker 及本地 / blob 字体，没有开放 object / frame 或任意脚本；依赖的 worker、CMaps 与标准字体在构建中打包。Markdown 不执行原始 HTML，公式使用受限 KaTeX；外部图片 Markdown 不自动抓取，以附件工具保存原件。

画布的 pointer capture 限于标题栏 / 形状本体拖动、八方向调整尺寸、连接与平移。调整上 / 左侧时把移动和尺寸作为同一事务提交，撤销一次恢复整个框；Escape / pointer cancel 放弃预览。旧摆放缺少高度时继续自动高度，纯左右拖动不强制固定高度；首次垂直拖动以实际渲染高度为起点。固定高度的长内容在框内滚动，图片按比例完整显示，图片像素和附件原件不改变。同一内容的不同摆放各自保存宽高。输入、滑块与长笔记内部滚动具有独立处理；在手势结束才提交几何命令，不把每帧拖动写进正文或文档历史。
