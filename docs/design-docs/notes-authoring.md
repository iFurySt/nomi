# 文稿写作与目录

状态：2026-10-25，本机 Electron / Web 第一版已实现。入口为 Canvas 上方的「文稿」，路由 `#/notes`。

## 用户流程

- 新建文稿、编辑标题，正文默认富文本。支持段落 / 一二三级标题、粗斜体、列表、待办、引用、代码块、链接、表格与 KaTeX 公式；点击公式即在就地浮层内输入 LaTeX，连续输入即时预览，Esc 或外部点击结束，无额外保存按钮。浮层随公式和视口定位，保留原公式位置与输入焦点。
- 当前只提供富文本写作，移除模式切换、文件导入、导出及重复撤销 / 重做按钮；历史仍可用键盘操作。只有实际编辑才序列化 Markdown，打开文章不写回原文。Tiptap Markdown 仍为 beta，不能承诺任意扩展语法无损转换。
- 既有 YAML front matter、Liquid、原始 HTML、Markdown 图片、脚注和引用式链接的内容块保持安全只读预览和原始源内容，防止富文本编辑改写未知语法；当前不展示源码编辑，不执行模板或请求远程图片。唯一 HTML 换行例外是管道表格单元格中的无属性 `<br>`，它对应编辑器已有 hardBreak；Canvas / 离线预览也只将这一安全写法转成换行，不开放通用 HTML。
- 标题中的 Enter 进入首个可编辑正文，输入法组词确认不触发跳转；搜索期间新建文稿会清空筛选，使当前新文稿保持可见。
- 正文默认连续输入，Enter 继续段落，无需插入文字。短文下方及正文列外的留白同样显示文本光标，点击进入最后一个可写区域的末尾，不添加空段落、不产生保存写入，也不强制滚动；正常段落、标题和控件仍按自身点击位置处理。格式与插入入口集中在正文旁的上下文菜单和选区浮层，没有顶部固定格式栏或底部插入工具条；非文本内容有清晰边界与调整控件。图片 / 实验前后自动提供输入位置，首字输入时才存为 Markdown block，打开文章不生成空块。上下方向键在正文首尾可进入前后文字区域。
- 粘贴富文本时规范化空的普通 `div` 容器，保留空段落；纯文本连续换行逐行保留，代码块仍按原始代码粘贴。保留公式等已知语义容器，不对非空 HTML 容器作通用改写。空行保存重开后保留；明确的 Markdown 标题、列表、引用、代码围栏和表格粘贴后转换成可编辑富文本；Shift 粘贴保留纯文本。没有复制进剪贴板的纯 CSS 外边距不推断为空行。
- Notion v3 专有剪贴板（`text/_notion-blocks-v3-*`）用于恢复其对外 HTML 省略的空文本块。与默认富文本解析结果逐块校验类型 / 数量 / 文字后，只补入原位置的空段落，样式与链接沿用原节点，列表保持分组，遇到空段分割的编号列表延续序号。当前支持能逐块对应的平面文字、标题、列表、待办、引用和代码；嵌套源块、未知结构、局部选择不匹配或无专有数据时沿用普通粘贴。已有空段落的 HTML、强制纯文本与代码上下文保持原粘贴行为。
- 空段落悬停或聚焦时，左侧显示加号，菜单可直接选择正文 / 标题 / 列表 / 待办 / 引用 / 代码、表格、公式、图片附件与交互实验；选择类型替换当前空段，不额外留下空段。正文左侧整条留白可悬停命中当前纵向块，已有内容左侧显示当前类型图标与六点拖拽柄，类型属性菜单保留转换、基础文字样式、移动 / 删除及「在下方插入」。表格属性菜单另有增行 / 增列 / 删行 / 删表操作。「放到画布」也位于块菜单内。软换行属于同一段落，引用 / 表格以整体为单位；有序、无序与待办列表按每个列表项命中和拖动，父项携带子列表，嵌套项也可独立移动。
- 选中文字后就近出现样式浮层，支持粗体、斜体、删除线、行内代码、链接、清除格式与行内公式。按钮与链接 / 公式弹窗保留原选区；同一选区切换格式沿用首次浮层锚点，避免 DOM 分段和字体变化导致跳动；Escape 收起，中文输入法组合期间不显示，滚动和窄窗口会重新定位。块属性菜单里的基础样式作用于当前块。所有样式通过上下文工具修改。
- 拖拽支持段落内排序、跨文字区移动、图片或实验插到两段文字之间，整个文稿滚动面板按纵坐标显示落点并在边缘滚动，正文左右留白与块间隔也可放置，指示线与 drop 共用同一命中结果；离开面板或结束拖动清理指示线。块拖动期间隐藏编辑器原生细 drop cursor，统一显示文稿落点线，普通文字拖动保留原提示。列表项在同列表内重排、跨列表或文字区域移动时保留内容，按目标列表适配 item 包装，移走唯一项会清理空列表容器。分割正文与修改引用作为一个文稿事务提交；拖动期间内容已改变则拒绝过期位置。上移 / 下移跨过一个相邻可见块；相邻 Markdown 记录含多个段落或列表项时，只跨边缘节点，必要时在同一事务分割正文，不跳过整个 Markdown 记录。键盘撤销 / 重做使用同一文稿历史，覆盖正文、块菜单及菜单关闭后 body 焦点，避免只恢复一侧文字造成重复；搜索框、公式输入和弹窗保留自身按键语义。异步附件插入保留原始位置快照，原文改变时要求重新选择。
- 粘贴、剪切、拖放与后续输入使用独立历史边界，避免快速修改后一次撤销连带吞掉刚粘贴的整段内容。当前编辑器保留最近 40 个源快照的选区，文稿历史恢复文字时同步恢复原选区 / 光标并保持可见；未知快照使用有效位置回退，页面重开只恢复内容，不持久化撤销栈或光标缓存。
- 图片 / 附件及交互实验通过插入入口加入，可排序或移出当前文稿；移出的原块与画布摆放保留，支持撤销。
- 文稿列表支持右键菜单与行尾更多按钮删除。删除会移除 Note、它的画布摆放及相关连接，只有不再被其他文稿或独立摆放引用的所属内容才被移除；资产原件保留以支持撤销。删除后可立即「撤销删除」，也可用文稿撤销恢复。
- 交互实验可以添加 Softmax 温度样例、导入受支持的 `.nomi-ui.json`，或引用已有画布交互块。直接操作组件时保留独立的个人学习状态。
- 通过粘贴加入正文内容，图片 / 文件仍可从块菜单保存附件原件。
- 「放到画布」为同一 Note 创建一次摆放；修改文字与标题不产生内容副本。

文稿聚焦反馈遵循设计约定：列表项、更多按钮、标题和上下文样式按钮不显示 outline / box-shadow 外框，标题也无聚焦底线；键盘聚焦使用轻微底色和文字变化。

待办项的勾选框与第一行文字横向对齐，长文字在文字列内自然换行；NodeView 显式携带 taskItem 类型标记，使交互渲染、粘贴与样式选择器保持一致。

### 斜杠插入菜单

正文的独立段落从 `/` 开始即可打开紧凑的内容块菜单，继续输入中英文关键词过滤，方向键循环选择、Enter 插入、Esc 或点击外部关闭。菜单与 gutter 共用类型目录，覆盖正文、三级标题、列表、待办、引用、代码、分割线、表格、公式、文稿、图片 / 附件与交互实验。代码、网址、普通句中以及嵌套列表 / 表格中的斜杠保留文本语义。当前不在特殊语法的只读预览中启用。

菜单同时提供「画布」，可用 `/画布`、`/canvas`、`/绘图` 搜索并直接插入。菜单锚定斜杠位置，不随关键词长度横移；空间不足向上展开，窄屏限宽、内部滚动，选中项在键盘操作和窗口缩放后保持可见。组合输入期间暂停菜单键盘处理和更新，候选确认后再过滤，避免抢占中文输入法。

普通块在一次编辑事务中替换命令段落。公式、附件、文稿和实验走已有编辑 / 选择流程，确认后替换命令，取消保留原文。异步插入同时校验来源快照和命令原文，防止误删随后编辑的文字。所有变更进入共享文稿历史；空标题使用合法 Markdown `# ` / `## ` / `### ` 保留类型，避免撤销重做或重开时退化成正文。

回归入口：`node scripts/check-notes-slash.mjs`；构建后运行 `NOMI_SLASH_PRODUCTION=1 node scripts/check-notes-slash.mjs` 可直接验证生产 bundle；`NOMI_SLASH_MANUAL=1` 可打开隔离资料库进行手动验证，不操作实际文稿。

## 文稿内画布块（2026-11-03）

从空行加号、块属性的「在下方插入」或 `/画布`、`/canvas` 选择「画布」。正文中只展示内容预览，不显示绘图工具条；空画布显示「双击开始绘制」。双击预览（键盘 Enter / Space）打开接近全屏的编辑窗口，直接复用已有 `CanvasWorkspace`。形状、文字、连线、对齐、分组、缩放、笔记、图片附件、交互实验和 AI 生成入口使用同一套实现。点击右上「完成」回到文稿。

每个块拥有独立场景，修改不会添加到全局 Canvas，也不会在外层文稿树中生成场景内笔记。编辑提交立即进入父文稿的保存队列和撤销历史，不另建资料库；取消手势仍沿用既有 Canvas 行为。编辑窗口中的 ⌘Z / Ctrl+Z、撤销 / 重做按钮可正常使用。Esc 优先取消当前 Canvas 操作和选区，使用「完成」退出编辑。打开 / 关闭、平移、缩放不改变文稿内容。每次打开按当前窗口适应内容，视口仍单独保存。

预览复用同一形状 / Markdown / 附件 renderer 与连线几何，根据全部摆放、自动高度内容和连线的实际范围裁切留白，等比缩放到正文宽度并调整块高度（最高 640px），不依赖编辑时的平移缩放位置。窄屏预览完整显示，编辑窗口保留 Canvas 的空间布局、平移与缩放。预览控件为只读；交互实验进入编辑窗口后可操作。

`type: "canvas"` 块内的 `scene` 使用同一 `CanvasDocument` IR，但禁止再次嵌入画布。场景附件原件仍由父工作区平台仓库持有，正文与 GenUI 源文件在 `.nomi/canvases/<blockId>/` 下外置。单页导出保留场景和原件，离线阅读使用同样的内容预览。导入独立副本重新映射外层块和附件 ID，内部场景身份属于本场景。只读旧手绘叶节点用于保留本轮未发布原型数据，不再提供第二套手绘编辑器。

验证：`node scripts/check-notes-canvas.mjs`，隔离 Electron profile 验证插入、双击复用编辑器、原生形状移动 / 文字 / 绑定连线、完成后自适应、撤销重做、视图不写正文、全局画布隔离、重开、深浅色 / 窄屏和离线预览。core / host 单测覆盖场景校验、递归拒绝、事务、附件来源、嵌套源文件外部编辑和独立导入。

## 文稿层级与侧栏

每篇文稿既可以写正文，也可以包含子文稿，不引入文件夹类型。侧栏用缩进与展开按钮呈现层级，行尾加号 / 更多 / 右键均可新建子文稿；选择新页会展开其祖先。展开状态按本机 profile 保存，搜索匹配标题与正文并保留祖先路径。键盘方向键在可见文稿间导航、展开或收起。

文稿行的加号 / 更多使用覆盖式操作区，默认不占标题宽度，仅悬停、键盘聚焦或菜单打开时浮现；触摸设备保持入口可见。长标题平时使用右侧渐隐，悬停稍候后从开头平滑横向滚到末尾，末字完整停在按钮左侧，不循环、不自动回弹；移开回到开头，栏宽或标题变化重新测量。减少动态效果偏好下禁用滚动并保留完整标题提示。动画与 hover 均不写正文或 revision。

「移动到…」可将已有文稿及其子树放入其他文稿或根目录，不复制正文或画布摆放，也不能移入自身或后代。文稿顶部固定面包屑显示祖先 / 当前文稿及各自图标，祖先可点击返回；根文稿也显示当前名称。长标题省略并可查看完整标题，深层级可横向滚动，切换页面或调整宽度保持当前项可见。父页正文下方提供子文稿集合：默认文稿块视图（图标与标题紧邻、轻下划线），可切换紧凑表格（名称 / 子文稿数量，每行一篇）。视图偏好按本机 profile / 文稿保存，切换不修改正文或 revision。长标题省略，保留完整名称提示，图标固定尺寸不参与文字列拉伸。删除含子页的文稿先明确确认范围；一次事务删除整棵子树、所属画布摆放与连接，保留外部共享内容，撤销整体恢复。

鼠标按住文稿标题移动超过 6 逻辑像素开始拖动，普通点击仍选择文稿，加号 / 更多 / 展开按钮不参与拖动。行中部高亮表示移入该文稿末尾；上下边缘按相邻可见行解析插入位置。展开父页 A 与首个可见子页 B 之间的间隙，不论命中 A 下边缘还是 B 上边缘，都表示插入 A 下、B 前；折叠父页下边缘仍表示整棵子树之后的同级位置。插入线留在实际命中间隙，并以缩进表达目标层级。列表末尾留白表示移到根级末尾。折叠目标悬停 650ms 自动展开，靠近列表上下边缘自动滚动。拖动只预览，松开时通过同一个 `move_note` 事务提交并选择来源文稿，⌘Z / 重做与正文共用历史。自身 / 后代、原位顺序、列表外释放、Esc、指针取消和窗口失焦不写入正文或 revision。排序基于完整兄弟集解析，搜索 / 折叠仅改变展示；触屏保留滚动与菜单移动。

侧栏右边界可以拖宽；默认 240、范围 160–480 逻辑像素，并随可用窗口宽度收窄以保留正文空间。左右方向键微调，Home / End 调到边界，双击还原默认宽度，Escape / 指针取消撤回当前拖动。栏宽随视图状态按本机 profile 保存，丢失捕获提交最后可见宽度，仅显式取消才回退，不进入正文历史；窄窗口采用可滚动的纵向文稿树并隐藏宽度手柄。

数据采用可选 `Note.parentId`，省略为根级，`notes` 数组顺序定义同级顺序。所有父引用必须存在且无环；既有平铺文档无需迁移或写回。单篇导出移除父引用，只导出所选页自身，避免悬空父关系与泄露其他页。

参考：[飞书我的文档库](https://www.feishu.cn/hc/zh-CN/articles/918479526636-%E4%BD%BF%E7%94%A8%E6%88%91%E7%9A%84%E6%96%87%E6%A1%A3%E5%BA%93)、[子页面列表](https://www.feishu.cn/hc/zh-CN/articles/780474929438-%E4%BD%BF%E7%94%A8%E5%AD%90%E9%A1%B5%E9%9D%A2%E5%88%97%E8%A1%A8)。仅采用页面层级与导航模式；本轮没有新增云端共享或权限继承。

文稿最近选中项按本机 profile 单独保存为视图偏好。Canvas 或其他页面返回无参数的文稿入口、刷新及重启后，恢复最后打开且仍存在的文稿；显式 `note` 链接及前进 / 后退导航优先。记忆中的文稿已删除或更换资料库后不存在时回退到第一篇现有文稿，空库清除记忆；不写入正文、revision 或撤销历史。

## 表格与目录

表格使用轻边框、柔和表头、统一单元格内边距和圆角外框，窄窗口在表格内部横向滚动；表格行列操作仍位于块菜单。

目录从已渲染的正文 h1–h3 自动获取，排除空标题与交互组件内标题，修改标题实时更新。默认正文左侧短线表达层级和当前章节，hover / focus / 点击展开，支持跳转、随滚动高亮和 Escape / 点击外部收起。宽度足够时可用图标固定目录并保留左侧栏空间，偏好在本机持久化；窄窗口恢复浮层，不覆盖成常驻侧栏。没有标题时不显示目录。未固定时短线和展开面板绝对定位在正文左侧留白，不为目录额外分栏；出现、消失、hover / focus 展开与收起均不改变正文的水平位置或宽度，仅 Pin 后参与布局。参考博客 reading-toc 的层级和滚动跟随，目录点击不改写 App 路由或正文。

固定目录与正文之间仅保留留白，不绘制竖向分割线。块属性菜单的焦点与指针事件会通过 React Portal 冒泡，因此正文工具柄只响应实际编辑器内的焦点；菜单打开期间忽略正文选区跟随与菜单焦点，避免旧光标改变目标块、菜单移位后松键误选操作。菜单保留视口边距，普通「放到画布」操作仍需明确选择。

所有类型图标（含空段加号）鼠标悬停 140ms 打开，离开后延迟 240ms 收起，菜单和子菜单之间可连续移动；触摸 / 点击和键盘仍可打开。六点不触发悬停菜单，开始拖动会关闭属性菜单。分割线保留 28px 行高，1px 灰色线位于行内正中。

公式属性菜单提供左 / 中 / 右对齐。布局在 LaTeX 源首行使用命名空间注释 `% nomi-align: left` / `right` 保存，居中省略注释，编辑浮层不显示这行元数据。注释不改变 LaTeX 公式语义，Markdown source 仍是唯一真相源；文稿 NodeView、Canvas Markdown 和离线文章读取同一布局信息。普通 Markdown 阅读器可渲染公式，但不保证识别对齐布局。

表格菜单提供复制文本与下载 CSV 图标：复制为制表符分隔的纯文本，下载为 UTF-8 BOM 的 CSV，保留中文、引号、单元格换行及合并格的矩形占位；复制成功用勾号反馈，失败可重试。此处只导出当前表格，不恢复整篇文稿导出入口。

## 代码与附件

代码块使用 CodeBlockLowlight / lowlight 常用语言集，保留 Markdown 围栏语言和代码原文，未指定语言时自动识别。编辑视图、Canvas 阅读与离线文章共用高亮配色与纯文本复制控件；复制图标位于块内右上角，悬停 / 聚焦显示，触摸设备常显。未知语言或超过 50,000 字符的高亮输入安全回退，代码不会执行。

文稿中的 image / file 移除外层卡片和类型标题。文稿内小图按原始尺寸居中，大图随正文宽度收缩；图片按钮不继承普通按钮内边距 / 悬停底色。文字片段按实际内容高度流动，普通列表使用紧凑项间距，保留显式空段落与嵌套层级。图片原件直接展示，下载图标悬停浮在图片内；图片块可选 `caption` 为最多 2,000 字的普通文字，与资产文件名 / 原件分离。下方灰色斜体居中编辑，沿用文稿自动保存、撤销 / 重做和共享数据；空说明不生成字段；提示只在未聚焦的悬停状态显示，点击开始输入即隐藏。点击图片或按 Enter / Space 打开大图浮层，复用已校验的本机原件，适应窗口与窄屏，支持 Escape / 关闭按钮 / 外部点击关闭并恢复图片按钮焦点；打开图片不写回。Canvas 可读同一说明，Markdown 输出图片替代文字与斜体说明，结构快照保留 caption，离线文章使用 figcaption。

PDF 通过按需加载的 PDF.js 本机分页渲染为 Canvas，页码 / 前后页和原件下载收在下方；不使用 iframe 或执行 PDF 脚本，限制渲染像素并取消旧页任务。worker、CMaps 与标准字体随构建本地打包，开发服务器只暴露固定依赖资源列表。生产 CSP 仅补充本地 worker / blob worker 和字体权限。小于等于 256 KiB 的纯文本、Markdown、CSV、JSON 可按纯文本预览；其他类型、加密 / 损坏 PDF 或预览失败回退为类型图标 / 文件名 / 大小 / 下载卡片。附件读取仍校验长度与 SHA-256，校验失败不提供未经验证的下载。

离线导出继续携带附件原件：图片说明和代码高亮可离线显示，PDF 目前保留原件链接，不把桌面 PDF 预览器加入发布包。

## 数据边界

`CanvasDocumentSession` 在整个工作台持有同一个 `useCanvasDocumentState`，避免切换到其他功能时丢失尚未成功保存的编辑。存储按 profile + document scope 隔离；桌面使用本地文稿目录，浏览器继续 IndexedDB，均通过 revision CAS 和附件 hash 校验，以文档提交作为原子可见边界。

正文仍为 `markdown.source`，Tiptap JSON 仅是编辑器内部状态。`set_note_blocks` 修改 Note 的有序引用，由现有 command transaction 校验，引用不存在的 block 时原子拒绝。交互定义使用原有 `InteractiveProgram` 和 `InteractiveRenderer`；不执行文稿里任意 JS，也没有 AI 自动改写文章。

相邻的空 Markdown 块显示为一个输入入口；仅打开文稿不改写结构。首次实际编辑时，在同一事务中移除仍为空的重复引用，保留原块及其他笔记引用，不折叠富文本内部的空段，也不跨附件合并。

文字与标题停笔 700ms 后合并保存，持续输入每 3s 至少触发一次；结构操作立即保存。失焦、切换文稿 / 路由和隐藏页面会 flush，写入串行且使用最新 revision。正常状态固定显示一个保存图标，悬停可查看是否已落盘，失败单独提示并提供重试。Electron 关闭窗口 / 退出时等待 renderer 的保存 Promise，失败时保留窗口；浏览器卸载仍有 pending 时阻止直接离开。保存失败保留内存内容，可重试。这是单机存储，不是云协作或 CRDT 同步。重启前确认保存图标的提示为「已保存到本机」。

## 底层导出契约（当前无 UI 入口）

`planNoteExport` 只选择目标文稿、按顺序引用的 block 和所需 assets；不包含其他笔记、camera、摆放、连接、账号或个人学习进度。

- **Markdown 包**：正文 `.md`、附件、离线阅读页、各交互实验 HTML、Nomi 文稿 JSON 和 README。Markdown 内交互为可点击的本地 HTML 链接；任意 Markdown 平台不会自动执行这些组件。
- **Jekyll post 包**：`_posts/YYYY-MM-DD-slug.md` 或 `_en_posts/...`，生成 layout / title / date / lang / tags / toc front matter，附带 `assets/nomi/slug/`。交互使用 `relative_url` iframe，`sandbox="allow-scripts"`，固定 900px 高。此操作不发布博客。
- JSX 运行时在构建时通过 esbuild 打包，发布快照携带 JS / CSS / 字体，无 CDN、无后端依赖。独立 HTML 用同一 React 交互渲染器及 core 运算；每次打开从定义默认值开始。
- `assets/nomi/slug/index.html` 是完整离线阅读页。Nomi JSON 保留结构，当前 UI 仅保留交互定义导入，不宣称已支持整个 ZIP 的恢复导入。
- 资产 ID 使用不区分大小写文件系统上仍唯一的十六进制文件名。缺少附件或 hash 不符时拒绝生成不完整导出包。
- 形状导出文字并给出提示，完整定义保留在 JSON。画布空间布局不会自动变成文章插图。
- 含旧博客 front matter 的导入正文仍原样保留；导出 Jekyll 前应在源码中整理，避免重复 front matter。发布元数据由底层调用参数提供，不作为文稿字段持久化。

## 文稿图标（2026-11-01）

## 正文文稿引用块（2026-11-02）

块菜单「内容 → 文稿」打开可搜索的文稿选择器，显示已有文稿及祖先路径；也可新建子文稿并在当前位置插入引用，一次事务完成。引用是独立 `note-reference` 块，复用块拖动、上移 / 下移、移出文稿和 ⌘Z / 重做。点击进入对应文稿；引用不复制正文、不改变已有目标的 parentId，不影响子文稿集合完整列出直接子页。

实时标题和图标来自目标文稿，目标删除或不在当前文档时显示禁用占位及保存的标题。仅移出引用块不会删除目标文稿，删除目标也不破坏引用所属文稿。允许循环引用，因为不递归展开正文。Canvas 使用同一个引用渲染；离线导出保留名称及 DSL，不包含引用目标正文。

新增类型需要支持 `note-reference` 的客户端；0.1.1 不认识这一内容类型，按原有规则拒绝写回，不能当作普通附加字段丢弃。只切换子文稿视图不会改变文档格式。
