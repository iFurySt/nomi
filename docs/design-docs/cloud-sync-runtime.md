# 个人云同步运行说明

2026-11-15：个人文稿同步 v1 已实现并完成本机隔离验证；后端已部署 amoylab，桌面同步已随 0.4.0 于 2026-11-16 发布。设计与默认调度见 [cloud-sync.md](cloud-sync.md)，验收进度见 [执行计划](../exec-plans/completed/20261115-personal-cloud-sync.md)。

iOS 从目录底部的账号入口进入原生登录或个人设置，固定使用官网。Apple / Google 首次登录按已验证邮箱匹配或创建账号。详见[移动端说明](../../apps/ios/README.md)。

## 桌面入口与边界

左下角账号菜单管理 Nomi 账号，设置中没有 Account 分类；ChatGPT 只在 Settings → ChatGPT 管理 AI 连接，两套身份、凭据与退出操作独立。Settings → Cloud Sync 只配置 Base URL，默认 `https://nomi.ifuryst.com`；留空恢复官方地址，旧 `/api` 后缀兼容，host 自动追加 API 前缀；地址由 host 持久化，退出后保留。远程必须 HTTPS，loopback 开发可 HTTP；拒绝地址里的凭据、查询参数与片段。已登录时改变服务器会拒绝，须先退出，避免将当前凭据发给其他服务。

未登录保持本地使用。在浏览器完成 Nomi 登录表单后即接入同步，不再有独立「开启同步」按钮；表单简短说明自动同步及本机备份。无云端文稿时创建并上传，单份时先备份再连接下载，多份才选择；取消选择不修改本地内容，可重试继续。不会按标题猜测合并。历史版本的已登录但未绑定 / 已暂停账号须显式继续后接入，不因升级或访问页面自动上传。账号由运维分配，当前保留私有账号分配方式。

左下角菜单顶部静态展示账号信息，底部直接 Log out，不打开账户弹窗；设备列表与详情 UI 暂时移除，菜单不请求 sessions API。多云库选择与冲突复核只在对应异常 / 设置流程中打开专用对话框。重新登录成功后仍尽力撤销本机旧会话；设备查询 / 撤销 API 与缓存保留。退出停用同步并删除本机凭据，保留文稿、outbox 和基线；联网时撤销当前会话。

同步身份包含服务、账号、云库和实际资料目录；目录变化暂停旧绑定。首次完成前不显示已同步。状态请求不能覆盖操作结果，连续提交只启动一次登录。

host 使用 Electron safeStorage 加密凭据，安全存储不可用时不保存明文替代品。renderer 只拿账号摘要、操作结果和显式请求的冲突内容，不拿 token。同步 sidecar 位于独立 userData/cloud-sync；正式版、开发版与隔离测试 profile 各自独立，不写入可携带的 `.nomi` 包。

设备列表由 host 持有加密 `devices.enc` 缓存，与登录身份（服务器 / 用户 / 会话）绑定；status IPC 只读本地缓存。当前没有设备界面，不主动发起 sessions 请求；未来重新启用设备入口时可先展示已有数据。并行请求合并，失败不清空列表，重启仍可立即读取。退出 / 重新登录清除缓存，成功撤销立即移除对应条目，并使旧在途刷新失效，防止被撤销设备回弹。缓存仅用于展示，不参与鉴权。

## 网站登录

左下角 Sign in 打开系统默认浏览器的 `{Base URL}/login?request=…`，邮箱 / 密码仅提交网站。网站成功后通过固定 `nomi://account/complete`（开发版 `nomi-dev://account/complete`）唤醒 App；链接不携带凭据。App 回到前台不等于登录成功，主进程必须完成领取与加密保存。

主进程生成内存内的随机 verifier，服务端仅持有 S256 challenge 和 5 分钟短期请求。App 每 1.5 秒查询，网站批准后通过 verifier 原子领取一次设备会话；重复领取、过期、错误 proof 均拒绝。取消后不接纳在途响应（若已产生会话则尝试撤销）；重启不恢复 verifier。网络异常可重新发起，领取成功但响应丢失可能留下未使用设备会话，可从设备列表撤销。网站使用 CSRF cookie / form token、HTTPS `__Host-` cookie、CSP nonce、no-store 和限流。网页可使用现有 Nomi 密码、Google 或 Apple。网页与 iOS 按同一供应商及稳定 subject 找回账号；首次登录以已验证邮箱匹配或创建账号。各设备独立领取、保存和撤销会话。

网页登录后自动同步：新账号上传本地资料库，单份云库先备份后连接，多份时打开专用文稿选择对话框。旧版本已登录但尚未绑定的用户，仅查看账户不会自动上传，需显式继续。

## 本地事务与恢复

core 定义实体投影、三方比较与可控时钟调度；host 持久化冻结的 request ID / payload，写入和目录 fsync 完成才发请求。确认只更新该批次的实体基线，不推进拉取游标，不清掉新一代输入。请求成功但响应丢失后重试原请求；409 明确未提交才可换新请求。

接收端先合并已知基线、本机持久内容与远端变化，再通过当前编辑会话检查 revision、正文内容、输入法组合和待保存状态。任何新输入都拒绝这次远端应用，稍后重新计算；不会直接覆写编辑器文件。远端应用后清除早于该事务的整文稿 Undo 快照，避免旧快照还原时静默覆盖云端改动；之后的新编辑仍可撤销。

同实体冲突以本地 sidecar 保存双方与基线，菜单仅在冲突时提供 Review changes，打开专用对话框查看并选择。选择前重新检查云端版本与本地内容；有后续编辑时要求重新查看。时间戳显示精度不构成竞争修改。选择前另保留该冲突副本。每次本地持久保存形成原子修改组，交叠保存保守合组；某组有冲突时保留整组，独立修改组继续同步。结构冲突暂停相关资料库提交。异常退出丢失保存分组边界时，以持久内容 / 基线对账保守合组，不猜测拆分。冲突查看带内容版本摘要，自动拉取刷新后旧选择会被拒绝。已处理冲突副本按最近 50 份或 30 天取并集保留；未处理冲突与 outbox 不清理。

保存事件、外部文件载入和前台扫描都进入对账；事件仅用于唤醒，持久文件才是上传来源。安静期 / 最大等待、节流和重试以设计数值为准；最早待上传时间、上次开始和退避时限写入设置，重启不会绕过退避。手动同步无本地变更时也立即拉取。

## 历史与恢复

账户面板已移除 Version history / View history 入口及其 UI。底层历史协议保留按块分页、恢复及把已删除块放回指定文稿的能力。当前版单独保存；归档版本保留最近 50 条与最近 30 天的并集。恢复是新的本地事务和云端版本，先备份本地库，不修改旧历史；当前块未同步、冲突、云端版本变化时拒绝覆盖。缺失的附件元数据从历史恢复，原件按不可变引用下载；缺失原件则整体失败。

服务启动和每 24 小时清理历史 / 90 天前连续日志前缀。`maintain` 默认只报告，`--apply` 执行；游标落在清理水位之前的设备通过旧基线 + 最新快照三方对账，不盲目覆盖。删除身份、提交收据与附件身份不随日志过期。对象审计保守保护所有已发布身份，只报告超过 7 天未发布原件，物理 GC 关闭。

## 运维边界

独立 Compose、显式 migration、配对备份 / 恢复与新库完整校验见 [部署说明](../DEPLOYMENT.md)。HTTP 日志仅记录操作类别、方法、状态码、耗时；不含正文、文件名、账号、token 或对象路径。账户菜单仅在冲突时提供复核入口，维护报告包含清理候选和未发布原件容量。无公开 metrics 服务或生产告警平台。

v1 限制：每库 live payload 4 MiB / 4,000 个实体身份（含 tombstone），单附件 20 MiB；旧收据与删除身份持续保留，原件无自动回收，需监控数据库 / disk 容量。运维可创建密码账号，第三方登录可自动开户。密码找回和共享尚未开放。历史恢复协议按内容块，当前没有用户界面入口，不提供整库任意时间点回滚；灾备恢复使用配对备份。

## 验证

- `./scripts/test-sync-server.sh`：隔离 PostgreSQL 18、Go race、身份 / 版本 / 对象异常。
- `node scripts/check-sync-package.mjs`：真实 Go API、独立原生资料目录、原件摘要与单块增量。
- `node scripts/check-sync-package.mjs --desktop`：真实服务 + 三个隔离 Electron 进程；独立 userData、资料目录、设备 ID 和登录凭据。覆盖 Base URL 配置 / 重启持久化 / 服务器切换保护、左下角 Nomi 登录、自动新建 / 连接、多个文稿选择 / 取消、无账户弹窗 / 无设备请求、菜单退出与设备 API 撤销，以及不同块离线汇合、同块冲突 UI 选择、外部 Markdown 修改、远端 Undo 保护、历史 API 恢复、丢失提交响应与在途新输入、重启重放、设备撤销 / 重登录和停用后本地编辑；产物写入忽略的 `.artifacts/sync-package`。
- `node scripts/check-sync-package.mjs --backup`：真实数据库 dump、不可变原件归档、全新数据库 / 空对象目录恢复、10 张业务表比对及摘要验证；拒绝非空目标和损坏备份。
- `pnpm exec vitest run packages/core/src/sync packages/host/src/sync-engine.test.ts`：调度时钟、三方合并、冻结 outbox、丢确认 / 在途输入、编辑器竞争、旧游标重建和过期冲突选择。

所有 fixture 为 synthetic 文稿，本机隔离进程不代表多台物理 Mac。未访问正式版资料。公网部署测试使用独立 synthetic 账号，不上传真实文稿；后端入口与运维见 [部署说明](../DEPLOYMENT.md)。

增量日志与历史分页同时受数量和字节预算约束，提交批次不拆分；首次全量为有预算上限的固定水位单响应。

移动端已接入同一 v1 实体协议，Duo 本地保存、账号与云库缓存、冲突副本及互通验证见 [移动文稿](../../apps/ios/README.md)。
