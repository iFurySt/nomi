## 交互规则

- 四角显示白底蓝边小方点；四边使用透明热区，方向光标分别为 ns / ew / 两种斜向 resize。多选只显示统一选框及四角，单项控件隐藏。
- 平移使用空格拖动、手形工具、中键或滚轮；空白左键拖动改为框选。Alt 临时取消吸附；Shift 拖动锁轴，Shift 角点缩放保持比例。连接圆点与缩放热区分开。
- 多选的移动 / 缩放 / 排列以一个命令批次提交，一次 Undo 恢复。预览与参考线不进入 DSL。两端都在选区内的手动连线折点随整体变换；仅一端选中时保持其用户折点，失效时派生路由回退。
- 组合存为平面的 Placement `group`，选择组内对象会选中全组。分组不把几何烘焙为位图，也不改变正文共享关系。锁定禁止普通 UI 修改，但不承担授权职责。
- ⌘ / Ctrl+D 创建独立内容副本；保留 Note 多摆放的原功能由内容列表「放回」和卡片复制摆放提供。独立副本重新映射 Note / Block / Placement / Group / Connector ID，内部连接跟随，外部连接不复制。附件只复用当前文档已经校验的不可变原件；跨文档缺原件时明确拒绝。
- 快捷键还包括 ⌘ / Ctrl+G / Shift+G 组合 / 取消、⌘ / Ctrl+Alt+L 锁定、Alt+A/H/D/W/V/S 六种对齐、Ctrl+Alt+H/V 等距、Shift+H/V 翻转、方向键微移。正在文本输入或打开面板时不截获这些键。

## 平台中立协议

Shape 新增可选 `shapeStyle`：受限 fill / stroke、透明度、宽度、线型、90° 旋转枚举、翻转、文字格式；Placement 新增可选 `group` / `locked`。几何形状按稳定枚举表达，固定轮廓位于 core，React 不是数据源。所有字段白名单验证，颜色不接受 CSS，链接限 HTTP(S)；旧 draft-1 无新增字段的文档仍可读取，旧客户端不保证读新字段。

形状最小尺寸为 16×16 世界单位，其余内容框仍为 160×120；上限保持 1600×2400。命令批次上限 600，同时继续受 2 MiB 文档及各对象预算限制。布局命令、组合与复制不依赖 DOM；自动内容高度只在布局测量时由 renderer 提供。完整文件化编码、原件包和 CRDT 仍是独立工作。

源码边界：`core/canvas/{document,shapes,layout,geometry,orthogonal}` 负责语义、验证和几何；UI 的 `SelectionToolbar`、`selectionClipboard` 负责编辑与导出；`CanvasWorkspace` 协调指针手势、选择和保存。当前 Workspace 仍较大，应在继续扩充笔迹 / 同步前拆分控制器。
