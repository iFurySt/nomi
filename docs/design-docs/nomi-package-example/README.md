# 可打开的 .nomi 样例

`学习计划.nomi` 是真实目录包，包含两层文稿、Markdown / 公式、交互温度实验和一个普通附件。内容均为合成样例，无用户数据。

在 Nomi 中使用 File → 打开文稿包（⌘O），选择本目录下的 `学习计划.nomi`。库外包会询问是否导入独立副本，原样例保持不变；macOS 类型注册后也可双击打开。

AI 可以先阅读 `document.json`，再编辑 `text/text.start.md`；`interactive/interactive.temperature.nomi-ui.json` 为完整交互定义。具体规则和共享引用边界见 [v1 格式契约](../nomi-package-format.md)。

这是当前 codec 生成并回读校验的真实样例，不沿用早期尚无 parser 的 KDL 文件示例。
