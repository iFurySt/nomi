# 连线编辑与浮动工具栏

状态：2026-10-25。根据用户提供的截图和 34 秒录屏逐项提取交互；参考视频只用于观察，不复制进仓库，不依赖第三方画板运行时。

## 体验与手势

- 选中对象的外侧圆点可直接拖出箭头；拖动或改接靠近目标时，只对源 / 目标展示贴在边界上的四个 n / e / s / w 关键锚点；其余边缘同样可吸附，按实际语义轮廓投影并显示独立实心吸附点，目标轮廓高亮。关键锚点附近优先吸附关键点。松手绑定 Placement / side 与可选相对 anchor，移动或缩放对象后跟随。
- 连接工具也可从空白拖出自由线。端点拖到空白变为自由世界坐标，拖回关键锚点或轮廓边缘重新绑定。Escape / pointer cancel 不提交。
- 选中连线显示两个端点圆圈，悬停使用四向移动箭头（`cursor: move`），锁定时保留默认光标；折线显示各段的蓝色控制柄，可拖动调整路由，端点绑定不改变。每次手势结束才写一个可撤销事务，预览不写历史。
- 改接头尾时固定另一端，按下仍保留原有路径，超过拖动门槛才实时更新原线；颜色、粗细、透明度、原有虚实、两端标记、标签与层级均沿用。预览和提交共享 core 的端点计算，拖到空白按相对方向生成自由端点，吸附则绑定目标；实际移动后不沿用原有手动折点，以自动路径作为首帧，再优先延续本次手势中仍有效的近优路线。为保持松手 / 刷新后一致，必要时将稳定路径保存为既有 `waypoints`。拖动只更新派生视图，松手写一个事务，Escape / pointer cancel 恢复原线，Undo 原子恢复原绑定与折点。
- 连线和形状工具栏的下拉项可由鼠标 / 悬空笔移入直接展开，移到相邻项切换；按钮与菜单之间保留 180ms 离开宽限，进入菜单即取消关闭，离开后自动收起。输入框聚焦时保持菜单，外部点击和 Escape 继续关闭；触屏与键盘保留点击操作。更多标记和图层子项也支持悬停展开。形状目录与 bar 图标采用固定 1.75px 描边和圆角线帽 / 连接，不随 100 单位形状几何缩细，图标视框保留描边边距：20px 目录使用 `-6 -6 112 112`，16px bar 使用 `-8 -8 116 116`，防止固定描边被自身 SVG 视口裁切。
- 选中线的下方显示不随 zoom 缩放的紧凑浮动工具栏（基础栏高 38px、按钮 28px、图标 16px）。位置基于路径边界，限制在视口内；连线与形状弹层共用实际尺寸测量，距工具栏上下边缘 6px，横向对齐触发按钮并约束在窗口内。下方空间不足时向上展开，展开更多标记 / 图层后重新测量，无固定高度预估；窄屏工具栏可横向滚动，弹层随触发按钮更新。标记菜单宽 128px、操作菜单 208px、其他面板 224px，按钮高 28px，与工具栏保持一致。拖动新线 / 改接端点期间暂时隐藏属性栏，松手后恢复，避免旧位置面板遮挡目标或自环；双击线或文字进入标签编辑。

## 绑定端绘制留白

逻辑路线与绘制路线分开。绑定点、命中热区、端点圆圈、折点和标签仍使用真实边缘上的逻辑几何，只有线身 / 标记绘制路径回缩。绑定端预留 3 屏幕像素净空，并补偿形状半边框和线帽；自由端不回缩。缩放时重算绘制间距，不改变世界坐标路由或 DSL。绘制间距不是可拖动自由端点，不影响移动 / 缩放 / 自环绑定。

路径按弧长裁切，L / Q / C 保留各自直线 / 二次 / 三次子曲线，不用折线替代曲线。非常短的连接按比例缩减回缩量，至少保留 20% 路径，避免首尾倒置。各类标记最前端的几何中心线与线身端点对齐，marker 的 16 → 10 缩放配合 1.6 单位描边，使实际描边与线身等粗；圆头 / 圆角自然覆盖同一尖端。refX 不额外增加描边半径，避免箭头后移后线身突出尖端。端部留白已包含线帽补偿。新建 / 改接预览和现有连线共用，PNG 导出沿用实际绘制路径；无新 DSL 字段，旧文档无需迁移。

## 拖动稳定性

新建连接离开起点 32 屏幕像素后启用自身吸附，避免刚拖出即吸回；改接已有连接直接允许自身绑定。双方可绑定同一 Placement，关键点与任意边缘都适用。

新建连接与改接共用世界坐标命中，不再通过 `elementFromPoint` 读取拖动中不断变化的端口 / 线条 DOM。吸附命中目标内部或距实际轮廓 16 屏幕像素以内，已绑定目标距轮廓超过 24 像素才脱离。关键锚点 10 像素内优先，已吸附关键点在 14 像素以内保持；离开后沿最近边缘连续移动。轮廓朝向需有 12 像素的距离优势才切换，避免角点抖动。自由端点朝向也采用 12 像素的方向优势缓冲，避免对角线或固定端点附近小幅抖动反复转向。所有缓冲均按 zoom 反算，不使用时间延迟或拖慢指针。

圆角 / 直角线在相同绑定与端点朝向下，将上帧路线的端段随指针调整；仍满足正交、端段朝向、无原路回折、无两端形状内部穿越，且长度与转弯代价未比新自动路线高出 `24 / zoom` 时继续采用。路径失效、明显绕远、绑定 / 朝向变化时立即自动重算。此状态仅属于当前手势，不改全局路由缓存，不跨手势隐式记忆。松手保存最后一次预览的连接对象，稳定折点使用已有 DSL 字段，无协议迁移；撤销恢复手势前的完整连接。

## 录屏中的工具项

1. 起点 / 终点标记与交换方向。基础菜单和「更多标记」提供无、开放箭头、实心 / 空心三角、实心 / 空心菱形、实心 / 空心圆、竖线、鸦脚、一对多、零对多、零或一、交叉，共 14 个枚举。
2. 16 个预设色、自定义六位十六进制颜色与 0–100% 不透明度。
3. 圆角折线、直角折线、直线、曲线；折线按两端朝向生成，从右侧连接目标顶部时先上绕再向下接入，避免在同一条腿上反向重叠；共线中间点合并，减少重复控制柄。实线、虚线、点线；1 / 2 / 3 / 4 px 粗细；交叉处跨线跳线。跳线处理线交叉，不代表复杂对象路径避障。
4. 添加 / 编辑文字、10–48 字号、文字颜色、粗体、斜体、删除线、下划线、左 / 中 / 右对齐及 HTTP / HTTPS 链接。标签通过 SVG text 安全渲染，不执行 HTML。
5. 更多：复制、复制为图片、粘贴、创建副本、上移 / 下移一层、置于顶层 / 底层、复制 / 粘贴样式、旋转 90°、锁定 / 解锁、删除。置顶线可显示在内容上方，普通线在内容下方；同一层内按连接数组排序。

复制使用 `nomi-connector/v1` JSON，复制出的端点解析为世界坐标，跨文档不携带悬空 Placement ID。粘贴 / 副本偏移 24 世界单位；旋转使线端点脱离原形状，围绕路径中心旋转 90°。这些变化不移动形状。复制为图片将受限 SVG 图元栅格化为透明 PNG 后写本机剪贴板；超大图片限制边长，失败显示错误。剪贴板拒绝文本写入时仍保留当次本机画布剪贴板，菜单可粘贴。样式剪贴板只复制格式，不改端点、标签正文或锁定状态。

锁定禁止 UI 改接、路由与格式修改、复制副本、旋转、删除；仍可选择、读取、复制、解锁。锁定是编辑体验状态，不是权限边界；DSL / AI 事务仍由上层授权控制。删除绑定形状仍会删除关联连接，Undo 原子恢复。

## 平台中立契约

`CanvasEndpoint` 为绑定端点 `{ placement, side, anchor?: { x, y } }` 或自由端点 `{ point: { x, y }, side }`，两者不能并存。`anchor` 两坐标均是 0–1 范围的归一化相对位置，仅允许绑定端点使用；省略时维持旧关键锚点。显示时将相对位置投影到当前语义轮廓，移动 / 缩放后重算世界坐标，形状替换或翻转 / 旋转后仍贴合当前轮廓。`side` 保留正交线路的出入朝向。自由坐标与折点均受 ±1,000,000 约束，最多 32 个折点。

`CanvasConnector` 保留旧的 `startArrow` / `endArrow`；可选 `startHead` / `endHead` 决定更精细的标记，缺省回退到旧布尔字段。UI 同步维护二者。新增可选字段：`color`、`opacity`、`width`、`lineJumps`、`locked`、`aboveShapes`、`waypoints`、`labelStyle`。所有字段白名单校验，颜色不接受 CSS 表达式，链接只允许 HTTP / HTTPS，数值、枚举、引用和文档预算继续严格检查。

轮廓投影使用矩形、圆角矩形、椭圆、多边形与固定曲线的同源轮廓；开放括号与无可见轮廓的文本使用框边界。关键点与任意边缘共用世界坐标计算，不以 DOM 或任意用户路径作为契约。多选复制 / 粘贴重映射 Placement 时保留 anchor，单条线复制则解析为自由世界坐标。

旧 draft-1 快照可直接打开，无需数据迁移；老客户端可能拒绝新字段，因此不承诺旧客户端读取新快照。完整文件包、协作、原生 renderer 和复杂路由避障尚未完成。

## 路由边界

自动圆角 / 直角折线读取两端形状 bounds，使用正交可见通道搜索避开端点形状内部；通常在边界外保留 40 世界单位，邻近形状挤压通道时缩到可用间隙的一半。这里只处理两个端点的边界框，不是遍历第三方对象的全局避障。不能仅因为端口间距为正就选 L 形或中分折线：形状缩小后，近乎齐平的端口可能只剩 1–2px 末段，圆角和箭头会覆盖它。近齐平的混合方向端口改走外绕，端点重合时保留可见折返环；镜头缩放不改变世界坐标路径。

同一 Placement 的自动自环强制向外绕行，主体路径避开向外扩展 40 世界单位的形状边界，首尾端段保持各自边缘方向；同侧、相对侧、相邻侧和重合端口均保留可见路线。直线类型的自环也走外侧折线，曲线类型沿外绕路线平滑转角，避免单根弦 / 贝塞尔曲线穿过自身。缓存区分自环与两个重叠但不同对象。旧自由端点不自动推断或改绑，须由后续拖动明确绑定。

手动折点优先保留，包括用户主动拖出的短端段。绑定对象移动 / 缩放使折点出现零长终段、反向进入端口、原路折返或斜段时，显示临时退回自动路由；不覆写 DSL 中的手动折点，对象恢复原位置时仍可使用原折点。

标签按折线累计长度的一半定位。端段达到 48、中间段达到 16 世界单位且至少 20 屏幕像素时显示拖柄；线段拖动支持与其他平行线段在 5 屏幕像素内吸附，Alt 临时关闭。形状 / 多选操作见 [选择与布局](canvas-selection-and-layout.md)。

## 验证

- 核心单测覆盖旧数据、完整新字段往返、恶意 / 超限输入原子拒绝、连接层级、自由 / 绑定端点、圆角路径、交叉点和折点随绑定移动。
- 路由回归覆盖实际近齐平缩小案例、4,624 组坐标 / 端口朝向组合、临界距离、重合端点及失效手动折点；Electron 原生鼠标缩小形状至 2px 端口落差，检查末段切向与多档镜头缩放。
- Electron Canvas smoke 用原生鼠标验证吸附高亮、边界锚点、改接和线段拖动 / 撤销，逐项操作菜单并验证保存与刷新。
- Electron 原生鼠标覆盖头尾改接、圆角 / 直角 / 直线 / 曲线、实线 / 虚线 / 点线，检查按下不跳变、固定端不动、移动端跟手、原格式与标签保留、预览和提交路径一致、单次历史以及取消 / 撤销；计算样式检查端点为 `move`。
- 稳定性回归覆盖 0.5× / 1× / 2× 下吸附进入 / 退出、目标中线、自由朝向、双端绕行与明显移开后的重新路由；原生鼠标对起点 / 终点 / 新建三种入口，在四类临界位置各连续往返 17 帧，每帧采样线路 65 个位置，检查 1–2 屏幕像素抖动未触发大幅跳线、预览不写库、松手一致及原子撤销。
- 任意边缘回归覆盖矩形四边、菱形斜边、椭圆弧线、圆角及全部固定形状的翻转 / 90° 旋转轮廓，严格拒绝越界 / 非数值 / 混用 anchor。原生拖动检查新建及头尾改接、独立吸附点、连续小幅往返、移动 / 缩放跟随、刷新恢复与撤销。
- 自环回归覆盖四种路线 × 全部 16 组端口、重合端点、同侧 / 近角边缘、移动 / 缩放与关联删除；原生鼠标对新建 / 起点 / 终点连续拖动检查自身吸附、底部向上接入、路线不穿形状、单次保存 / 撤销及刷新恢复。
- 留白回归验证绑定 / 自由端、粗边框 / 线帽、自环、圆角和精确 Bézier 子曲线、短线预算；原生 SVG 检查多倍率下端部间距、逻辑锚点 / 命中路线不变、全部标记前沿，以及预览 / 提交 / 复制为图片。
- 箭头尖端回归将真实 SVG marker 与同粗细连续 V 形 / 线身的独立栅格结果比较，覆盖起点 / 终点、1 / 2 / 4 px 粗细及 0.5× / 1× / 2.5× 缩放；防止只验证留白而遗漏线身突出尖端。
