# 桌面正文按块保存

用户反馈千篇资料库修改一段正文落盘约 16 秒，希望在继续迁移之前修复开发版。

- 编辑器为已验证的文档建立块索引，以字节差额检查 JSON 容量。普通输入和连续输入合并只通过 IPC 发送已改正文，包含结构变化的批次走完整事务。
- 文件宿主索引所有者和便携副本，在修改前核对受影响的源文件及版本。正文和增量检查点共用可恢复事务。结构提交合并检查点，更换资料库时物化最新版本。
- 在独立临时库用 1,002 篇文稿、3,348 个块、1,218 个附件记录复测。旧路径同机单块落盘 14.628 秒。新路径分六个块连续保存 24 次，中位数 77 毫秒，P95 为 116 毫秒，最大 121 毫秒。每次包内仅写两份正文，目录遍历、附件读取与整库快照写入均为零。
- 隔离 Electron 编辑器从输入到“已保存”实测 883 毫秒，包含默认 700 毫秒防抖，该次宿主保存为 95 毫秒。重开后的完整 IR 与预期一致。上述时间为本地持久化，未计入云端同步。
- 覆盖共享副本、旧版本冲突、外部编辑、结构保存、目录搬移、检查点重建及中断恢复。正式版迁入需等待包含容量和保存改动的版本。
- 479 项单测、类型检查、构建、文稿目录 Electron smoke 与基础 CI 通过。额外在千篇库的编辑器中执行撤销和重做，两次均发送单块修改并逐块核对。开发版已重启，文稿页显示已保存。直接启动 smoke 的侧栏折叠检查曾出现一次重挂载断言，单独复跑通过。
