# iOS 文稿选词工具栏与连续排版

参照系统备忘录的录屏，文稿键盘上方的工具栏采用原生横向分页。开始输入时显示 Aa、清单、表格和附件链接等操作。选中正文后自动滑向文字样式，手动滑回插入页时保留选区。系统开启「减弱动态效果」时直接切页。

Aa 在正文底部打开格式面板并收起键盘。用户可滚动、重新选词、连续套用或撤销粗体、斜体、下划线和删除线。关闭面板时回到当前文字继续输入。附件入口复用文稿的 Markdown 链接操作，可填写附件的共享地址。

`ManuscriptFormat.swift` 管理两页工具和格式命令。`ManuscriptEditor.swift` 在原生文字编辑器中保留第一响应者及选区。`ManuscriptPreview.swift` 与 `Reader/reader.jsx` 在富文稿中按正文块和 UTF-16 范围应用命令，重绘后恢复选区。下划线以成对的 `<u>` 标签保存。阅读器和原生文字排版均能显示。

七项渲染与输入测试、原生文稿编辑界面回归均已通过。覆盖含 emoji 的选区、叠加与移除样式、点选下一段文字批量排版，以及面板开关前后的键盘与选区。开发构建已安装到配对 Duo。[输入、选词和面板换选的实测画面](../../generated/verification/mobile-documents/duo-selection-format.jpg)

Duo 模拟器折叠外屏的三个方向与展开内屏的四个方向均实测了 Aa 面板开闭、键盘切换和连续格式操作。选词自动切页及手动滑回插入页在内屏四向和外屏 270° 通过。外屏竖向与 90° 横向的模拟触控未稳定形成文字选区，这两个方向的双击选词切页仍待真机确认。
