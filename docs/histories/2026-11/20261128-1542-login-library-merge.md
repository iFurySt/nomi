# 桌面登录时合并本地与云端文稿

首次连接已有资料库曾直接以完整快照替换本机文稿。桌面同步现在先备份，再按稳定身份合并。文稿和块序列可合并两端独立插入，旧桌面与手机的工作区默认标题及画布标识可兼容，同一块的不同内容保留供复核。已有绑定继续使用原基线及持久提交队列。更换已绑定的账号时，合并前须确认目的账号。

变更涉及 core 的 reconcile、host 的 SyncEngine / CloudSyncHost 以及桌面连接流程。类型检查、生产构建、473 项单测（两个 worker）及隔离 Electron / Go / PostgreSQL 回归通过。专项涵盖登录前独有文稿、同名异 ID、断网双端编辑、会话撤销期间的修改随后在两端可见、同块冲突、重启重试和跨账号保护。

依用户授权将登录前的备份增量恢复到开发版。已保留两个来源的内容，核对本机完整投影和服务端确认版本，开发版重启后文稿列表与保存状态正常。此轮未发布。
