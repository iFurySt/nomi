# Duo 底部工具栏下的正文

折叠外屏和展开内屏横放时，格式栏的安全区把整段正文截在按钮上方。阅读视口现在统一延伸至底边，原生文本、离线 Markdown 和多块文稿将底部工具栏需要的留白放在滚动内容末尾。编辑时沿用键盘避让。

在同一台 Duo 模拟器上滚动长文，逐一检查折叠三向和展开四向。[七种姿态的底部截图](../../generated/verification/mobile-documents/duo-floating-bottom-bar.png)记录了按钮和正文的相对位置。原有内屏竖向 UI 回归已扩展到其他姿态，检查原生文本及 Markdown 视口是否覆盖按钮底缘、滑动后视口是否仍覆盖按钮，并检查编辑区避让屏幕键盘。该用例在修复前的外屏失败，修复后通过。

根目录 AGENTS.md 已加入 Duo 跨姿态改动与验收约定。
