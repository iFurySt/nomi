## 2026-11-23 22:35 · Duo 目录显示文稿层级

「移动文稿」中能够看出父子关系，侧边栏却把已展开的子文稿与根文稿画在同一列。

侧边栏和移动面板现在共用层级缩进。根文稿沿用原有边距，子文稿每级缩进 12 pt，六级封顶，给长标题保留空间。有子级的文稿显示叠页图标。选中背景和点击区域仍覆盖整行。点父文稿打开正文并展开子级，再点可收起。

层级计算与行布局见 `ManuscriptOutline.swift` 和 `NomiMobileApp.swift`。在 `ManuscriptMoveTests.swift` 中补充了三级文稿的顺序、缩进及收起父级时隐藏后代的回归断言。交互约定已同步到移动端 README 和 UIUX 参考文档。
