# 文稿 AI 右侧栏与引用批注

## 用户诉求

将文稿右上角小 AI 浮窗改成类似 ChatGPT / Notion 的右侧聊天栏，支持多轮对话，并将选中文字或内容块附上批注再发给 AI。

## 实现

- 独立消息滚动区、底部输入与模型 / 停止控制，可拖宽、收起、新对话；窄屏抽屉、浅深色样式。收起保留当前会话，切换文稿 / ChatGPT 账号隔离。
- 新增 host 固定 `note-chat` 协议：流式 Markdown reply 与严格 commands 分离。普通问答不写正文，显式生成可插入 Markdown / 原生交互块。续轮修订仍仅替换本会话未被手动修改的结果。
- 选区工具栏和整块属性菜单可添加引用。引用附评论、编号高亮、移除；新增后直接聚焦评论。原文变化则取消失效高亮，保留引用快照；引用不会进入保存内容。
- 批注预算由 core / host 验证，图片与附件只传块引用元信息；成功历史按完整消息对裁剪并保留最近一次生成定义，考虑上下文 JSON 编码开销。失败 / 取消不入历史，迟到响应不写入。
- 同步生成设计文档、质量证据与 execution plan。

## 边界

会话仅内存保存，不是持久云端聊天或多人评论。未接入图片视觉理解、任意 HTML / JS、文件或网络工具。此前未提交的 Diagram 工作与独立 HTML 隔离提案保持原样；本轮未提交、推送或发布。
