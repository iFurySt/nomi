# Canvas 工具栏与 0.1.3

## 用户诉求
画布工具恢复为左侧竖排，删除全局标题和保存状态的常驻文字；模板集中在工具栏。文稿内双击打开的画布需要 Close、可编辑名称、Esc 返回。合并两个会话的改动提交并发布补丁版本。

## 修改
- 共用左侧紧凑工具栏，形状网格和模板菜单向右展开，短屏工具栏可滚动，浮层按窗口避让。
- 全局画布隐藏名称；保存状态仅保留读屏提示，错误仍可见并提供重试。
- 文稿内画布左上角 Close 与名称输入，名称写入场景并沿用父文稿保存 / 撤销。
- Esc 从普通画布返回文稿；弹层、编辑、拖拽优先取消当前操作。适应内容为左侧工具栏预留空间。
- 收入已完成的 Canvas AI 生成、ChatGPT 登录回调和内嵌 Canvas；发布版本 0.1.3，CI 增加三项专项 UI 回归。

## 验证
类型与 305 项单测通过；Canvas 完整回归、内嵌画布重命名持久化 / Esc / 模板 / 窄屏检查通过。AI / 登录 / 独立桌面 smoke、生产构建和基础 CI 通过；实际 App 已重启并检查菜单展开、文稿内画布和 Esc 返回。

发布预检修正：内嵌画布新增后斜杠菜单实际为 16 项，更新旧数量断言，并显式检查“画布”入口；生产构建下斜杠菜单完整回归通过。首次流水线在制品发布前停止，修正后重新触发同一尚未发布的版本。
