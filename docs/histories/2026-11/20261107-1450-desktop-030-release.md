# Desktop 0.3.0 发布

## 用户诉求

递增一个中版本，发布本轮已完成的功能与体验改进。

## 变更

- 根包及桌面版本统一为 0.3.0，发布 tag 为 desktop-v0.3.0。
- 汇总文稿上下文 AI、代码块视口与交互、统一 Tooltip、目录留白与画布导航 / 键盘改进。
- 文稿 AI、目录和 Tooltip 独立回归加入双架构发行门禁。
- 沿用 Developer ID 签名、公证、DMG 和 Sparkle 更新清单发布顺序。

## 验证

- 本机类型、368 项单测、生产构建与基础 CI 通过。
- 开发版保存后重启；正式版与用户正文不参与发布验收。
- 首轮发行预检发现生产斜杠菜单测试未同步 AI 入口数量与键盘索引；已更新回归，重新发布尚未公开的版本。
- 同步形状回归的共享 Tooltip 选择器，图标回归等待实际定位并容忍 1px 像素舍入；本机 28 种形状、图标、登录和更新回归通过。
- 目录居中回归改按可用视口计算留白，排除 CI 常驻滚动条宽度；增加本机常驻滚动条场景验证通过；显式模拟 1200 / 820 / 390px 视口，避免 hosted Mac 屏幕限制，并用中间章节验证滚动定位，避免末章底部吸附规则干扰。
- 内嵌画布手势回归统一到 Chromium 实际接收的整数指针坐标，增加可指定小窗口尺寸与细分失败诊断；1024×768 本机回归通过，原有焦点 / 光标锚点 / 文稿视口不变断言保留。
- [双架构流水线](https://github.com/iFurySt/nomi/actions/runs/42350813356) 通过，公开发布 `desktop-v0.3.0`，源码固定于 `bd4efb6`。
- 公开 arm64 / x64 DMG 的长度、SHA-256、Sparkle Ed25519 和 stapled 公证票据验证通过；两个更新清单签名、版本及 URL 通过。
- arm64 App 严格深度签名、公证票据、Gatekeeper 与内嵌版本通过；验证卷已卸载，未启动正式版或替用户执行跨版本安装。
