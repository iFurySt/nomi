# 2026-11-07 | 移除重复的图形颜色菜单

## 用户诉求

图形内部不再显示旧颜色下拉菜单，统一使用下方属性工具栏。

## 改动

- 删除 CanvasWorkspace 在图形文字编辑状态插入的原生颜色 select，以及 canvas-legacy-tone 定位样式。
- 保留既有 tone 数据兼容与属性栏的填充 / 边框调色能力，统一全局及文稿内嵌画布入口。
- 更新画布选中属性契约。

## 验证

类型检查、生产构建通过。重启 Nomi(Dev)，在独立测试画布绘制圆角矩形，双击进入文字编辑，确认内部无颜色下拉菜单；使用下方工具栏改为绿色后再次进入文字编辑，截图确认颜色生效且没有重复入口。正式版与真实文稿未参与验收。
