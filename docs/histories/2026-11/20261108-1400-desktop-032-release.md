# Desktop 0.3.2 发布

## 用户诉求

再发布一个桌面补丁版本。

## 改动与动机

- 根包与桌面版本递增至 0.3.2，收录文稿原生交互块 AI、就地输入与连续调整、一键下载后保存并自动重启更新。
- 更新用户发布记录与执行计划；沿用双架构签名、公证和 Sparkle 发布流程。
- 新更新交互在安装 0.3.2 后生效，从旧版升级仍由旧版 UI 执行。

## 验证

类型、382 项单测、生产构建、文稿 / 画布 AI、更新 host / UI / native driver 回归及 make ci 通过。远端双架构和公开制品校验待流水线完成后补充。

## 发布预检修正

首次双架构预检发现两处测试环境差异：AI 输入框在较窄虚拟屏幕正常向左避让，测试却要求始终对齐光标；文件包完整落盘往返在共享 Intel runner 上超过默认 5 秒。定位测试改为验证视口内贴近光标，并支持 1000px 窗口回归；仅这项文件系统集成测试采用 15 秒预算，断言保持完整。版本尚未公开。
