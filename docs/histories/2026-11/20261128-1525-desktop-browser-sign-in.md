# 桌面网页登录与断线恢复

用户点击登录后看到等待气泡、取消入口及底层网络错误弹窗。账号菜单现在保持原来的登录入口，重复点击可重开同一次网页登录。连接失败用工作区的短提示引导重试。

桌面同步通过独立 Electron 网络会话使用系统网络配置。发起请求遇到短时连接错误后最多再试一次；等待批准期间保留原 verifier 及五分钟有效期。账号与文稿同步继续走原有的领取、保存与首次连接流程。

类型检查、生产构建、470 项单测和工具提示专项通过。三个隔离桌面进程使用真实本地服务验证断网提示、重开同一次登录、网页认证、回跳与后续同步。全套同步回归曾在外部 Markdown 跨设备读回时读到旧值，完整复跑通过。官网验证使用临时请求确认登录表单可达，未提交真实账户凭据。确认开发版文稿已保存后重启并复核了账号菜单。
