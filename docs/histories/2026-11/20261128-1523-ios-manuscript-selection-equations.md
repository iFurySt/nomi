# 稳定 iOS 文稿选区、公式输入和截屏后的编辑状态

用户在清单里选字时遇到意外换行，点公式时光标会移到其他位置，输入中截屏偶尔会留下白色的键盘区域。

在 `apps/ios/Reader/reader.jsx` 将 Markdown 软换行及续行缩进保留在可编辑文字范围之外。替换选中的词时保留嵌套清单、原始换行和缩进。点正文时沿用实际命中的位置，只有点到最后一段下方的空白才续写到文末。

行内和独立公式共用 `ManuscriptEditor.swift` 的键盘上方输入框。`ManuscriptPreview.swift` 将输入绑定到当前公式的源码范围，正文同步显示排版结果。输入未闭合的 LaTeX 时保留最近一次成功的预览。公式被键盘遮住时只滚动所需的距离。

`NomiMobileApp.swift` 在用户向下拖动文稿并收起键盘时结束编辑。系统截屏或临时窗口导致的键盘隐藏会保留编辑会话，并在窗口恢复时检查和恢复原输入焦点。

使用图中的中文嵌套清单验证选区替换前后的行位置及 Markdown 源码。用行内和独立公式验证编辑、保存、重开。六项渲染及输入测试通过，其中一项分别模拟先截屏后失焦和先失焦后截屏，检查输入框与选区恢复，并检查已切换到其他输入框时焦点留在新位置。

在 Duo 模拟器的折叠外屏三个方向和展开内屏四个方向，均能打开公式、抓取画面并继续输入。模拟器的拖动收键盘用例在点击屏外的虚拟按键时中止。真机已安装开发构建，自动化测试进程在建立连接前退出，物理按键截屏引起的白屏仍需真机复核。


## 公式的选中态和键盘预览

独立公式现在沿用正文段距，默认字号下上下各留 12 pt，并给分式留出少量内部空间。点按行内或独立公式时，正文标记当前公式，键盘上方的圆角面板将光标放入等宽源码输入框。输入框上方显示同一份离线排版结果，表达式未闭合时保留最后一次成功的结果。点按其他位置或完成编辑后清除正文标记。

排版继续由阅读器中的 KaTeX 完成。面板接收生成的 MathML，逐次更新预览内容，源码输入框在预览刷新期间保持焦点。

Duo 模拟器折叠外屏三向和展开内屏四向均实测了行内与独立公式。点公式后直接输入，核对原生输入框的位置和预览中的新增字符。离线排版测试验证上下段距、选中标记的清除和未闭合表达式的预览保留，UI 测试验证保存重开。开发构建已安装到配对 Duo。[行内公式与独立公式实测截图](../../generated/verification/mobile-documents/duo-equation-live-preview.png)
