# 文字格式的黑白圆形选中标记

根据用户提供的 Nomi 与备忘录截图，将键盘格式栏及 Aa 面板中已开启的文字样式统一为居中的实心圆。图标的背景最大直径为 38 pt，按钮仍使用原有整格点按范围，支持同时显示多项已选状态。浅色外观使用黑底白图标，深色外观使用白底黑图标。标题和正文等文字标签沿用适合标签宽度的胶囊形状，使用同一套黑白配色。侧栏的完成编辑按钮同步使用黑白强调色。

实现在 `ManuscriptFormat.swift` 和 `NomiMobileApp.swift`。验证使用同时套用粗体、斜体和下划线的文稿，比较键盘工具栏与 Aa 面板的实际截图。[键盘工具栏深浅色对照](../../generated/verification/mobile-documents/duo-format-selection-colors.png)

在 Duo 模拟器的折叠外屏三向和展开内屏四向，分别检查了以上三个图标在键盘工具栏及 Aa 面板的实心圆轮廓，覆盖浅色与深色外观。文字样式叠加与取消的回归测试通过。开发构建已安装到配对 Duo。

## Format 面板的分段选中态

后续参考图展示了面板内部的分段样式。键盘上的单项快捷按钮保留黑白圆形。打开 Aa 后，粗体、斜体、下划线和删除线在同一胶囊组内各占一格，点按可独立叠加或取消。已选分段整格填色，相邻选项之间用细线分隔。段落选择器呈现三级标题与正文的字号和字重。面板标题与 Aa 的辅助功能名称已统一为英文 Format 和中文「格式」。[模拟器中的浅色与深色面板](../../generated/verification/mobile-documents/duo-format-panel-groups.png)

Duo 模拟器已在折叠外屏三向和展开内屏四向打开新版面板，使用含三种叠加样式的选区逐项核对分段位置、填色及面板边距，覆盖深浅外观。两个回归测试通过，覆盖中文面板名称、返回键盘继续编辑、保存与样式切换。开发构建已安装到配对 Duo。
