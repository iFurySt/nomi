# 2026-11-07 | 文稿画布预览、间距与悬停控件

## 用户诉求

统一正文画布前后间距，空态参考飞书插画，悬停显示尺寸点和操作栏。

## 改动

- 消除末段和画布两层下边距叠加；保留用户空段。
- 同源预览增加简洁空态、八向缩放、紧凑浮栏与连续 hover 命中区。
- 支持编辑、下载离线画布包、临时缩放 / 适应、恢复自动尺寸。
- preview 展示尺寸独立于场景坐标，放开单笔提交，Esc 取消；核心校验和文件包往返保留。
- 增补独立 Electron 测试和格式 / 写作契约。
