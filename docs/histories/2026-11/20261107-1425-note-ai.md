# 文稿上下文 AI 生成

## 用户诉求

把画布 AI 推广到文稿，通过光标或选区调用，带标题和前后文，动态生成交互实验等内容。

## 实现与取舍

- 复用紧凑生成输入框、模型选择、真实 delta 命令解析和取消；增加文稿 `/ai`、选区 `/` 与选区工具栏入口。
- 捕获标题、选中文字及前后各 1500 字符；host 验证独立上下文预算，不读其他文稿与附件，不开启工具。
- 使用临时 decoration 在所在段落附近展示逐块输出；最终一次插入原生文字/实验或内嵌画布，保留原文，一次撤销。
- 原文/块顺序改变拒绝插入，取消、切换页面与关闭丢弃迟到结果。
- 沿用既有受限交互 DSL；不新增任意脚本或通用 BPE 等仿真运行能力。

## 验证

- 类型检查、Web/Electron 生产构建通过。
- noteAI 与 ChatGPT host 两组共 28 项单测通过。
- 隔离 Electron 文稿生成、既有画布生成与文稿内嵌画布回归通过；使用合成账号/响应，无线上推理调用。
- 已退出保存完成的开发版并重新启动，Computer Use 验证实际 `/ai` 菜单与连接入口。开发版未连接 ChatGPT，在线生成尚未验收；正式 App 与真实写作未操作。
