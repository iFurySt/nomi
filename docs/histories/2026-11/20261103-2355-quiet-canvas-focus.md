# 安静写作、全视口画布与快捷键聚焦

## 用户诉求
移除画布“双击编辑”和正文写作占位提示；文稿内画布充满窗口，删除黑色焦点框；Option+E 直接聚焦已运行的 Nomi，不再短暂启动另一个实例。

## 修改
- 删除可见预览提示和 title tooltip，保留无障碍标签及键盘打开能力；正文默认 placeholder 为空。
- 内嵌画布使用全视口尺寸、零边距 / 边框 / 圆角；画布按钮、名称和菜单使用底色焦点反馈，普通卡片选中移除黑色外框。
- 本机 Hammerspoon 的 Nomi 专用快捷键优先查找正式 / 开发 bundle 的既有进程与窗口，取消最小化并聚焦；均未运行时才启动正式版。不改变其他应用快捷键，配置备份留在临时目录。
- UIUX 标准与画布 / 写作契约同步更新。
