# 桌面 0.4.0 发布

用户要求提交推送并发布中版本，版本由 0.3.3 提升至 0.4.0。包含可选个人云同步、网页登录与 App 回跳、精简账户菜单和紧凑设置，以及已合入的 BPE 引导交互。独立的 HTML 隔离设计草稿不纳入本次提交。

根与桌面 package 版本同步，功能记录更新；发布使用 desktop-v0.4.0 的双架构签名、公证和 Sparkle 清单流程。发布前类型检查及 65 个文件 / 452 项单测通过，前轮三套隔离 Electron 的 12 类同步回归和实际开发版菜单验收通过。正式发布与公开制品校验结果在完成后补记。

首轮双架构应用回归与签名通过，均在 Apple notarytool 提交返回非 JSON 时失败，版本未公开。新增手动只读公证检查 workflow，先定位凭据 / 服务错误，避免盲目重复完整构建；诊断不输出历史或密钥，临时凭据结束即清理。
