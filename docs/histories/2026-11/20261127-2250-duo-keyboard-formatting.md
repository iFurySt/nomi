# Duo 键盘上方的文稿格式栏

用户在折叠外屏点进正文时看到两排工具，正文也被截在格式栏上缘。原先 SwiftUI 为整排格式工具预留了安全区，WebKit 又为可编辑的 Markdown 提供了一排表单导航控件。

文稿现在按屏幕键盘实际占用的空间显示格式栏。格式栏在正文可用区域居中，避开系统侧栏和固定目录。滚动视口一直延伸到键盘，工具所需的留白随文末滚动。收起键盘同时关闭 Aa 面板；在较矮的横屏上，展开面板后可以滚动选择格式。Markdown 正文和表格使用同一个 WebKit 编辑器，移除了它自带的上一项、下一项和完成栏。保存文稿仍通过 Nomi 的完成编辑操作。

验收覆盖折叠外屏的竖向、左右横向，以及展开内屏的竖向、倒置、左右横向。逐一对照阅读与键盘输入状态。[Duo 七向编辑截图](../../generated/verification/mobile-documents/duo-keyboard-formatting.png)

切换输入方式时，编辑器仍持有焦点就继续编辑。原生输入在保存前提交组字，收尾时的文字变更也不会重新打开编辑会话。模拟器的四项渲染测试和四项编辑界面测试通过，另实测了 Markdown 下拖收起键盘后回到阅读。开发构建已安装到配对 Duo。
