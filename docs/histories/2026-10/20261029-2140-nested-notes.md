# 层级文稿与可调整侧栏

## 用户诉求

先提交并推送此前已验收成果，再参考飞书实现每篇文稿下可以新建文稿的灵活层级，并支持拖动文稿列表宽度。

## 实现与边界

- 既有桌面 / 画布 / 文稿与定位调整保存为基线提交 `25a53a9`，已推送 main。提交前检查暂存文件范围、凭据特征与大小，类型 / 374 单测 / 基础 CI 通过；运行数据、凭据与构建结果不进入提交。
- Note 增加可选 parentId，沿用 notes 数组定义同级顺序，不引入文件夹或第二份树。校验父引用、循环关系；旧平铺文档不写回迁移。move_note 支持带后代移动和根级提升，不改变正文、稳定 ID 或摆放。
- 侧栏新增展开 / 折叠、行尾新建、更多 / 右键的新建与移动、键盘树导航，搜索显示命中页及祖先。子页正文上方有路径，父页下方有子文稿链接。删除父页先确认子页数量，原子删除子树、相关摆放 / 连线；共享块仍保留，支持统一撤销。弹窗关闭后主区焦点也能撤销移动。
- 分隔条原生指针捕获拖宽（160–480）、键盘左右 / Home / End、双击复位与取消。宽度 / 展开状态按本机 profile 保存，不增加正文 revision；宽度随状态及时保存，丢失指针捕获时提交最后可见宽度，仅显式取消才回退，避免重启丢宽度；窄屏保留可滚动的纵向树。
- 单篇导出去掉父引用，画布独立复制子页不携带外部父页；同时复制父子时把内部父关系映射到新副本。补齐原子拒绝、删除共享内容 / 连接、导出与复制边界测试。
