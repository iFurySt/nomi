# Nomi iOS 1.0.1

## 简体中文

- 正文采用系统字号，默认 17 pt，阅读和编辑时都能跟随 iPhone 的文字大小设置。
- 在 iPhone Duo 上，文稿可以滚过悬浮工具栏。点按正文或表格时保持阅读比例，待办复选框与首行文字对齐。
- 点按 Aa 设置文字和段落格式，一键插入清单或表格，在单元格旁即可增删行列。
- 新增简体中文和英文界面。

## English

- Notes now use the system body text size, 17 pt by default and following your iPhone’s Text Size setting as you read and edit.
- On iPhone Duo, notes scroll beneath the floating controls. Tapping text or a table cell keeps your reading scale, and checkboxes line up with the first line of each item.
- Tap Aa to format text and paragraphs. Insert lists and tables in one tap, then add or remove rows and columns directly in a table.
- Nomi is now available in English and Simplified Chinese.
