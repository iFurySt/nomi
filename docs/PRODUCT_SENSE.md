# 产品判断原则

Nomi / 知己是个人一站式工作台，连接学习、笔记、信息 hub、知识、健康和财富管理，并可扩展到家庭成员。完整定位见 [产品规格](product-specs/personal-workbench.md)。

- 首先服务一个人的长期上下文和日常任务，再增加家庭协作；健康和金融是领域能力，不代表整个产品。
- 优先让真实资料容易进入、持续积累、可检索、可引用；AI 的价值来自对上下文的理解，而非增加聊天入口。
- 领域模块复用基础能力，但保留各自的数据语义；不把医学、资产和学习进度硬塞进同一指标体系。
- 当前优先继承 AIFi 桌面成熟交互和 ChatGPT / Codex 基础，保留 iOS / server beta；按使用价值逐项裁剪金融专用功能。
- 信任、内容归属、来源与可控性优先；个人内容不会因加入家庭而自动变成共享。
- 当前能力、示例、缺失数据和未来方向必须明确区分，不以空入口冒充功能。

- 交互学习是首要场景：用户能改变参数、观察变化并保存进度。AI 生成的交互内容要成为可继续编辑的长期资料，普通交互在本地执行。
- DSL 共享语义与测试，不强制共享 UI 框架；原生平台能选择合适控件和地图提供者，同时保留数据、状态和动作的含义。
