# iOS 文稿首发

目标是用现有 Nomi 的 iOS 1.0 商店记录提交当前 SwiftUI 客户端。保留本地文稿、第三方账号和同步。分开记录代码推送、生产升级、构建上传、Apple 处理、审核提交和公开发售。

- 提交并推送已有移动端、账号和目录改动。确认商店 App、签名团队与 1.0 草稿。
- 为已登录用户提供二次确认的账号注销，清除该用户的云端资料和原件。用独立数据库验证隔离，升级生产前用现行流程备份。
- 在官网发布隐私和支持页，接入 App。检查商店截图、支持信息、审核联系人、演示凭据及隐私披露。
- 生成 Release archive，验证上传和构建处理结果，在商店资料准备好后送审。只使用既有的一台 Duo 模拟器。

## 2026-11-23 首发进度

- iOS 1.0（38）已上传，Apple 处理结果为 `VALID`，已选入 iOS 1.0 商店版本。已保存英文与简体中文商店资料、效率分类、年龄分级回答和审核登录说明。
- 官网 [隐私政策](https://nomi.ifuryst.com/privacy/) 和 [支持页](https://nomi.ifuryst.com/support/) 已公开，并接入应用和商店。生产发布前已完成配对备份。独立测试账号验证了服务端注销、会话撤销和账号隔离。
- 已在现有 Duo 上采集构建 38 的真实文稿截图，并验证简体中文 Duo 截图在 Apple 处理完成。
- 商店送审校验仍要求主语言的常规 iPhone 与 13 英寸 iPad 截图、公开的 App 隐私回答、价格及内容版权声明。Duo 截图是独立展示位。审核草稿尚未提交。
