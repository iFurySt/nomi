# 移动账号入口和第三方身份

从目录底部进入账号，访客使用原生邮箱/密码、Apple、Google 登录，已登录时打开个人设置和退出。移动版固定连接官网，测试仅注入隔离地址。

复用现有设备会话。第三方登录验证供应商签名、受众、一次性 nonce 和稳定 subject；已有用户可从设置绑定，避免根据任意同名邮箱合并账号。Google 使用 Nomi 专用项目和 iOS 客户端，Apple 复用既有 App 标识。

验收分为服务端身份验证与重放保护、Duo 原生登录和设置、登录后文稿同步，以及真实供应商配置的可用性。

## 结果

原生账号页、Google 项目和客户端、服务端迁移及备份部署已完成。Duo 原生账号操作、双端文稿同步和正式站点测试账号往返已通过。Apple 主 App ID 已开通，开发签名已刷新，个人真机授权待验。参见[实现记录](../../histories/2026-11/20261122-1056-mobile-account.md)。

Duo 在线测试已从 Nomi 按钮打开系统认证窗口并识别 Google 登录表单；真实 Google 账号的同意与回调仍待账号持有人验证。
