# 子文稿视图与正文文稿引用

## 目标
修复子文稿图标被 flex 拉伸导致的稀疏布局；提供表格 / 文稿块视图，以及可插入正文的文稿引用块。

## 约束与决定
- 父子关系继续由 Note.parentId 表达；引用不改变父子关系、不复制正文。
- 使用显式 note-reference 内容块（documentId、noteId、title 回退），引用缺失时呈现不可打开的占位，禁止自动绑定其他资料库。
- 新类型旧版不能识别时继续拒绝写回；不得静默删掉未知内容。已有文稿不自动迁移。
- 视图偏好按本机 profile / 文稿保存，不修改内容历史；文稿引用插入 / 移动 / 删除共用原有事务和撤销。
- 导入时只重映射本次导入范围内引用，外部引用保留占位；单篇导出不携带引用目标正文。
- 真实用户文稿不用于创建或删除测试数据。
