# Duo 文稿格式与表格

沿用本机包与同步 Markdown 块的原文模型，把已有样式集中到 Aa，列表和表格一次点按后进入正文。表格的结构操作复用当前单元格，修改时保留源文中其他区块及 GFM 对齐。

1. 调整共用工具条并核对简中、英文标签。
2. 验证从原生正文进入表格，检查带转义字符的单元格、空单元格和行列操作。
3. 从设备资料库回读示例包，并检查新构建中的输入和保存重开。
