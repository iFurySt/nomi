# 文稿连续写作、合并保存与删除

状态：已完成，2026-10-25。

## 目标

停笔后合并写入，持续输入定期落盘，保存文案稳定；文稿列表右键菜单删除且可撤销；正文以连续输入为默认，移除插入文字步骤，非文本内容前后自动提供输入位置。

## 约束和方案

- 正文仍使用现有 Markdown / Note / Block；不重写未编辑原文。虚拟输入位置在实际输入时才产生文本块，并保持光标与 IME 状态。
- 格式工具栏集中显示，内容块标签和调整按钮仅用于非文本内容。
- 文本保存约 700ms debounce，持续输入最多 3s 合并写入；失焦、切换、离开时 flush；串行 CAS、失败可重试保持原有语义。
- 删除 Note 同时移除其 placement 与相关连接；只清除不再被其他 note / placement 使用的所属 block 和资产元数据，原件保留以支持撤销。
- 用户现有文稿不用于删除测试。临时 profile 验证输入写入次数、持久化、删除 / 撤销 / 共享、连续编辑和导出。

## 验证与交付

类型检查、核心 / 保存调度测试、Notes 与 Canvas Electron 回归、浅深色 / 窄屏截图。同步实现文档与 history。确认真实 App 已保存后构建并重启回当前文稿。
