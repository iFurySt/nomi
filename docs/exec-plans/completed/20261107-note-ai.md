# 文稿上下文 AI 生成

目标：光标/选区通过斜杠菜单或选区 AI 按钮调用已有 ChatGPT 生成流程，传标题、选区与前后各 1500 字符；流式预览，完成后原子插入，可撤销。

约束：不读取其他文稿/附件，不改原选区；沿用 portable IR 及能力限制，不能把静态说明当作可运行实验。只操作开发版与合成数据。

步骤：
- [x] 声明并校验有界上下文，复用生成聊天框和解析器。
- [x] 捕获光标/选区，接入 slash 与选区入口，可靠插入及冲突检查。
- [x] 单测与隔离 Electron 回归：上下文范围、流式预览、撤销、取消、输入法、切换文稿、过期位置。
- [x] 更新文档/history、构建、重启开发版并实际验收。

决策：生成纯 Markdown / Interactive 时作为正文块插入；包含形状或连线时作为独立内嵌画布插入。打开 AI 时捕获上下文快照；生成期间编辑目标块则拒绝插入，不把内容写到新位置。临时预览不落盘。


完成：类型与生产构建、28 项单测、文稿 AI / 画布 AI / 内嵌画布 Electron 回归通过。实际开发版重启后验证斜杠菜单和连接入口；未连接开发版账号，因此在线推理留待授权账号验证。证据记录于同日 history 与生成设计文档。
