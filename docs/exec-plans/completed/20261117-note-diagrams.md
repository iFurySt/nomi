# 文稿架构图按意图生成

## 目标

用户要求一句 Corpus 经 BPE Training 分叉到 Vocabulary / Merge Rules，再汇合为 Tokenizer。文稿生成应以节点连线为主，不能强制生成表格实验。

## 范围与约束

- 增加 portable draft-2 的 Diagram v1：有界无环图，节点引用已有安全 UI 子树，边只连接直接子节点，宿主负责排版。
- 架构图无需伪造控件；交互实验仍要求可操作输入。不开 HTML / JS 或外联，不自动修改真实文稿。
- BPE 示例直接计算固定训练预算的结果，Corpus 可编辑；用真实函数与输出，不硬编码结果。
- 旧客户端不支持新组件时明确拒绝，未来移动 renderer 可独立实现。

## 风险与验证

- 节点循环、悬空端点、超预算：核心校验与测试。
- 不同宽度 / 内容高度连线错位：自动分层、DOM 测量、宽窄深浅色截图及输入重算。
- 模型仍偏向表格：提示词优先辨别输出意图，提供架构图范例；实际生成验证与结构测试分开记录。
