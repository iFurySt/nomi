# .nomi 文件包第一版

目标：将已确认的目录包设计落成可编辑、自包含、可迁移的桌面格式；维持当前文稿 / 画布交互与用户资料。

参考：`docs/design-docs/nomi-document-package.md`。本任务保留既有未提交变更。

## 实施

- [x] 实现版本化 package codec：正文文件、交互源、原件、子包与画布引用。
- [x] 包成为内容来源，旧快照仅恢复 / 缓存；外部编辑校验、并发冲突、局部更新与可恢复结构事务。
- [x] 旧树 / 快照迁移，目录更换和独立包打开；macOS 注册与启动路由。
- [x] 真实目录单测及 Electron 回归，补充格式契约与 AI 编辑指南 / 样例。
- [x] 构建并正常重启正式 App，Finder 包展示、子包、直接编辑与内容恢复验收。

## 约束

首次迁移保留旧树与完整快照 / 原件，不做不可逆清理。资产摘要逐个验证，schema / 引用失败不切换。文件包不允许 symlink 逃逸或任意宿主执行。直接多文件写入仅在合法稳定状态后接收，不宣称任意外部工具具备原子事务。共享块需保留显式所有者及便携快照，不能默默拆成不联动副本。

## 验证

核心场景：新旧库、Markdown / 公式 / GenUI / 附件往返、子树移动 / 撤销、独立复制打开、共享内容、损坏包 / 缺原件 / 路径穿越、外部编辑 / 冲突 / 未来版本、重启恢复与原位目录更新。UI 验收沿用真实 App 与临时 Electron fixture，测试资料不覆盖用户正文。
