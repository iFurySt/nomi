# Duo 正文渲染与格式栏

目标是让移动端显示桌面文稿的 Markdown，并能在本机与同步 Markdown 块内设置格式。桌面选区工具提供粗体、斜体、删除线、行内代码、链接、清除格式和行内公式。移动端复用文稿的原始 Markdown，沿用现有标题、块 ID、保存、锁定和键盘收起流程。

1. 核对现有原生输入与桌面渲染的差异，补上列表、代码、表格及公式等正文展示。
2. 在正文底部添加阅读入口和键盘上方的编辑工具。命令应作用于当前块和选区，并能通过常规保存路径重开。
3. 在现有 iOS 27.1 Duo 上检查排版、格式命令、编辑与重开，并运行原有键盘和文稿回归。

## 完成情况

构建 37 已加入离线结构化正文阅读、底部阅读工具和选区格式栏。文稿仍使用原 Markdown 持久化。折叠外屏和展开横屏的正文操作回归通过，覆盖编辑、点完成、重开、勾选待办和返回编辑。WebKit 测试检查了实际 DOM 的语义结构，原生单元测试覆盖 Unicode 选区和多块待办写回。配对真机已安装并启动该构建。

模拟器旋转回归也验证了转向两侧及回到竖屏后自动保存、退出编辑并可继续输入。下拉收键盘的单独回归被模拟器屏幕外的键位坐标阻断，真机自动化会话也未启动成功。
