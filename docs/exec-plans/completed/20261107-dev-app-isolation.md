# 开发 App 隔离

- 目标：默认本地启动使用 Nomi(Dev).app，保留正式 Nomi 的窗口、文稿、凭据与更新路径。
- 实现：独立 bundle ID / userData / 默认文稿库 / 账号目录 / URL scheme；开发包不注册文稿默认关联，不启用正式更新。旧开发包和真实文稿不迁移、不删除。
- 验证：类型与构建、隔离 smoke、生成 plist / profile 契约检查，实际启动仅检查开发 App。
- 协作：将以后只重启和测试开发版写入仓库指南。
- 状态：完成。类型 / 构建、登录回跳单测、隔离 smoke 和生成包直接启动检查通过；Computer Use 确认 Nomi(Dev) 标题、独立文稿目录、未登录及禁用更新，未操作正式版。
