# 交互学习协议与温度探索器实现

## 目标与范围

基于上一轮 GenUI 设计实现首个可运行纵向切片：框架无关的声明式 IR 校验 / 求值 / 状态动作，React renderer、温度探索器、桌面学习入口、定义与个人学习状态分离、本地恢复，以及跨语言参考验证。

本轮优先把已有 IR 变成可以编辑、导入导出和实际运行的内容。OpenUI 文本前端、完整笔记 / 无限画布、真实 AI GenUI 生成、跨端云同步和手机发布另行推进，不将它们标作已实现。原生协议验证以独立 Swift 参考实现为目标，不改现有家庭 beta 的权限或 API。

## 约束

- 不替换已有应用或删除金融功能；保留当前工作区未提交内容。
- 不使用 eval、任意 JS / HTML 或额外模型请求实现滑块课程。
- 引用、组件 / 函数版本、预算、类型和状态均校验，非法程序不能覆盖最后可用版本。
- 程序默认值与个人状态独立；当前本机 profile 的数据隔离不冒充云账号权限。
- 最小闭环必须从真实桌面入口可达，并验证交互、重开恢复与错误路径。
