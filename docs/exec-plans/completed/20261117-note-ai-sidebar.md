# 文稿 AI 侧栏与批注

## 范围

以右侧可收起面板替换文稿右上小浮窗。正文旁独立消息滚动、底部输入、模型选择、停止 / 新对话。保留当前会话多轮上下文；关闭隐藏不丢历史，切换文稿 / 账户隔离。普通问答不写正文，明确生成时继续既有严格 DSL 及原子插入 / 修订。

选中文字或内容块可加入待发送批注，引用与评论分开；编号高亮属于视图状态，不写入 Markdown。仅显式选中的有界文本 / 块定义进入请求；图片和文件只发送元信息，不读取附件原件。批注可改评语 / 删除，旧文本修改后不错误标注新文本。
