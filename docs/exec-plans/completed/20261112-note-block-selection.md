# 文稿空白区域框选

目标：从正文左右留白拖出选区，按相交范围选择段落或完整非文本块，复制、剪切、删除与撤销接入同一文稿事务。

约束：只操作开发版；不改用户文稿。保留文本原生选择、编辑器输入和块内交互。共享内容块只从当前文稿解除引用；附件复制校验当前库原件。拖动不触发文稿写入。
