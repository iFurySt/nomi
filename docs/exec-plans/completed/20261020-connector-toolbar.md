# 连线锚点与浮动工具栏

## 目标

根据用户提供的截图和 34 秒录屏复刻连线选中态、靠近形状时的关键锚点吸附，以及随连线定位的下方浮动工具栏。完成后构建、确认保存、退出重启 App 并前台验证。

## 录屏提取的范围

- 起点和终点标记菜单、更多标记、交换方向。
- 颜色面板、预设 / 自定义颜色、不透明度。
- 圆角折线 / 直角折线 / 直线 / 曲线，实线 / 虚线 / 点线，四档粗细、跨线跳线。
- 添加文字、字号、文字颜色、粗体 / 斜体 / 删除线 / 下划线 / 链接与对齐。
- 更多菜单：复制、复制为图片、粘贴、副本、四档层级、复制 / 粘贴样式、旋转、锁定、删除。
- 选中线的端点圆圈和中间段控制柄；拖线靠近形状时显示边界上的四个关键锚点，吸附点实心高亮。
