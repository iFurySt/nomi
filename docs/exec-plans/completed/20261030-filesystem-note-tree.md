# Finder 文稿树

## 目标

用户明确选择 Finder 文件夹层级直接对应文稿树。默认库的 `文稿/` 下每篇文稿一个同名目录，父子按真实嵌套；稳定 ID 保存在目录元数据。App 的创建 / 重命名 / 移动 / 删除 / 撤销写回结构，Finder 的创建 / 改名 / 移动 / 删除读回。

## 决策与约束

- 正文、共享块、画布与附件继续严格 DSL，不转成有损 Markdown；目录元数据只负责身份和显示顺序，层级以目录实际位置为准。
- 既有磁盘快照自动迁移为真实目录；重复标题、安全文件名与大小写冲突有确定性处理。
- 结构更新采用准备目录、恢复日志和保留旧目录，跨文件提交可恢复；外部变化先检查，禁止覆盖。
- 桌面定时读取并在回到前台刷新。无本地待保存修改才安装外部快照；冲突需保留本地草稿，不静默丢失。
- 目录更换带上文稿树及恢复资料；未提交的上一轮改动原样保留。

## 验证
