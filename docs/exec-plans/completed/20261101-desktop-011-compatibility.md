# Desktop 0.1.1：兼容读取与补丁发布

## 目标与边界

修复旧版遇到新增文稿字段时整库加载失败，发布签名、公证的 0.1.1 双架构 DMG 和 Sparkle feed。包含本轮已完成的导航、更新入口、文稿图标和空白菜单改动。保留用户文稿，尤其不编辑个人文章；保留已安装 0.1.0 供用户升级测试。

## 设计

同一 schema 的附加 JSON 字段不解释但原样保留，已知字段、引用、JSON 安全 / 大小限制继续校验。未知主版本、块类型和交互程序能力继续拒绝写回。包 manifest 和逐篇 document 的附加元数据在重组和保存时保留；不能简单 strip 后保存。

## 风险与验证

0.1.0 二进制无法追溯修补，需要升级到 0.1.1。未知字段仅为可选附加元数据；改变必需语义必须升级 schema。测试覆盖读入→编辑→保存→重开，以及包外部新增元数据的稳定往返。发布后不覆盖版本化制品。用户亲自完成 0.1.0 自动升级，不能把初始化检查称为安装验收。

## 本机验证

从 desktop-v0.1.0 的 parser 和合成 icon 文稿复现相同错误。38 文件 / 285 单测、类型、构建、桌面 smoke、IME、文稿图标、更新 UI / host / native driver、make ci 全部通过。Computer Use 退出已安装旧版后启动新构建，文稿列表、图标和正文恢复，显示已保存；未修改用户文章，安装的 0.1.0 二进制保留。

## CI 修正

第一次发布 run 的 Intel IME 回归在固定 600ms 重载断言失败，arm64 已通过应用校验。将回归改为等待实际保存状态与 IndexedDB 正文、did-finish-load 和选中篇正文恢复，分别报告持久化 / 加载失败；CI VM 使用软件渲染以避免 EGL 初始化失败。0.1.1 尚未公开，修正测试后更新待发布 tag 重新构建，不替换已发布 DMG。
