# 文稿 AI 就地输入与连续调整

## 目标

`/ai` 在光标或选区下方展开；发送后移到右上角，原处显示生成骨架与流式内容。完成后保留会话，后续指令替换本次生成的内容组。

## 边界与风险

- 复用现有 DSL 与原生交互块，保持画布生成兼容。
- 会话仅留在内存，携带有限成功轮次；取消/失败不写入文稿。
- 继续调整前校验生成内容仍连续且未被用户修改，原正文不覆盖；每轮提交可单独撤销。
- 仅使用隔离测试文稿与 Nomi(Dev)。

## 步骤

- [x] 光标定位、停靠动画与生成占位。
- [x] 保留对话、传递成功结果、原位置原子替换。
- [x] 回归定位、流式、继续调整、撤销、取消、冲突与画布生成。
- [x] 构建、重启开发版，截图验收并同步文档。

## 完成证据

- 37 项针对性测试、类型检查、生产构建及文档检查通过。
- 文稿 Electron 回归覆盖连续调整、单轮撤销、取消/失败保留、撤销后过期结果保护、骨架、定位与深色窄屏；Canvas 生成回归通过。
- Nomi(Dev) 重启后，Computer Use 使用已连接账号在独立验收文稿中完成两轮在线生成/调整，确认原生交互块保留滑块与实时数值，输入框仍可继续聊天。
- 当前会话仅在内存保留最近成功结果；重新打开需新建会话，不恢复历史会话。
