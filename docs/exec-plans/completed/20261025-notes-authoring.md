# 文稿：富文本写作与文章导出

状态：已完成，2026-10-25。

## 目标与范围

在 Canvas 下新增「文稿」入口，以富文本为默认写作界面，保留 Markdown 编辑、公式、笔记内交互实验、附件与导出。用户写正文，Agent 制作交互组件；DSL 留在底层。第一版针对本机笔记和文章，不宣称已替代全部 Notion 能力或完成云协作。

## 设计与约束

- 复用现有 CanvasDocument / Note / Block、命令校验、IndexedDB 和独立 study state；Canvas 与文稿读取同一内容，摆放不等于内容副本。
- 富文本编辑器只是 Markdown block 的编辑投影。未编辑时不重写原文，未知内容保留源码，交互和附件继续是独立 block，不经过有损 Markdown 转换。
- 通过已有 React 运行时展示 DSL；文章导出提供普通 Markdown 和 Jekyll post 包，附件及交互定义随包保存，交互在导出页面可运行。
- 本轮并行中的 Canvas 连线修复不属此任务；仅最小接入公共导航与持久化，保留全部未提交工作。
- 不执行真实 AI 推理或自动发布，不把账号、设备视图、个人学习进度写入文章导出。

## 步骤

1. 接入富文本编辑、公式和可逆的 Markdown 转换边界。
2. 加入文稿页面、同源笔记列表 / 创建 / 插入 / 排序和保存状态。
3. 实现 Markdown / Jekyll 包导出与交互独立运行时，保留所需原件。
4. 核心单测、实际 Electron 合成写作与重开 / 导出验证、布局截图、构建和仓库检查。
5. 更新说明与 history；确认真实 App 已保存，构建并重启到文稿页面。

## 风险与验证

重点验证中文输入、撤销、富文本 / Markdown 切换不误写内容、公式往返、跨视图共享、并发写入拒绝、存储错误、附件完整性及导出后交互执行。测试使用临时 profile 和合成资料，保留真实用户 Canvas。
