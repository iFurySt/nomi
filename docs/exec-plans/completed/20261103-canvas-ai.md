# ChatGPT 生成画布与交互实验

## 目标与范围
复用现有官方 ChatGPT 订阅授权，增加 Canvas AI 生成入口。输入描述，返回原生形状、Markdown、连线或现有 portable learning IR；验证、预览后原子插入，可撤销。首版不读取已有文稿或附件，不执行生成的 JS，不改写用户现有对象，不增加云端代理或 API key 计费。

## 风险与约束
模型结果不可信，仅允许新增且限定体积；校验引用、能力与预算，重新分配 ID。关闭 / 取消丢弃迟到响应。用户主动发送描述后才调用模型，订阅使用权与模型由已有 provider 校验。当前交互运算仅支持运行时已有集合，不声称支持任意实验。

## 验证
core 负例与原子命令、host 请求契约、类型 / 单测 / build；隔离 UI 验证预览插入撤销；实际 App 重启检查，真实在线生成单独记录。

- [x] 实现受限生成契约、提示、预览和应用。
