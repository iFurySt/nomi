# 将默认工作区落实为无限画布

## 诉求与纠偏

用户确认整体界面应为无限画布承载完整笔记，指出上一轮只有独立学习页面。此次直接落实画布主入口，不把控件样例当主产品界面。

## 本轮范围

- 默认 Canvas 路由、可平移 / 缩放的世界坐标、选择 / 拖动 / 调宽、适应内容、撤销重做。
- 平台中立 Document / Note / Block / Placement IR 与原子领域命令；Markdown 原文和交互定义独立于摆放。
- 长笔记预览、画布内编辑、聚焦编辑；支持 Markdown / LaTeX，图片和文件可放入画布。
- 既有温度探索器作为 InteractiveBlock 嵌入，同文档 / block 的个人状态独立保存。
- IndexedDB 保存结构与附件，camera 单独本机保存；明确错误、不静默覆盖损坏数据。
- 文档 DSL 的严格编辑 / 应用，持久化和真实 Electron 交互验证；重启用户正在试用的本地 App 到 Canvas。

KDL 文本前端、完整可移植附件包、手写、跨端 / CRDT、AI 生成及原生编辑器仍另行实现，不宣称完成。

## 结果

默认 Canvas、长笔记 / 附件 / 交互块、世界坐标交互、撤销、严格 DSL 与 IndexedDB 恢复已落实。16 个新增测试，全量 254 个测试；构建、完整桌面 / 画布 smoke 和既有导航 / 账号回归通过。已用真实 App 验证 Canvas 可见且保存完成。

具体实现与未完成边界见 [画布说明](../../design-docs/canvas-workspace-runtime.md)。原生手写、同步、完整文件包和 AI 生成仍为后续，不以实验室替代画布主界面。
