# BPE 引导原型转 portable DSL

目标：将已确认的逐词拆分 → 相邻对 → 合并 → 记录 → 特殊词元 → ID / 规则流程转为实际可导入 JSON，在开发版验收，保留输入与快速前后操作。

范围：增加必要的有界教学计算和通用 TokenFlow / Stepper 组件、Panel v2 条件展示；不执行生成 HTML / JS，不接入 Web 扩展，不发布版本。旧程序语义保持不变；新增 capability 明确拒绝旧运行时。

步骤：
- [x] 有界 BPE walkthrough 计算与行为测试。
- [x] 声明式组件 / 校验 / React renderer 和 DSL 示例。
- [x] 实际开发版导入、手动 / 自动、回看、完成、窄屏验收。
- [x] 文档、skill 能力说明与 history。

验证：独立语料断言、快速前后轨迹、空输入 / Unicode / 特殊词元 / 原预算；类型与构建，实际开发版操作。HTML 对照保留在会话预览；不承诺原生移动 renderer 或动画像素一致。

验收：类型检查与构建通过；5 个测试文件、54 个测试通过。开发版真实导入并验证自动拆分、手动回看、连续 54 次推进至完成、重启后进度保留；独立预览使用同一 React renderer 验证 390px 无横向溢出、清空输入、替换语料与保留句子的重置。最终默认语料输出 36 个词元（含 4 个示例特殊词元）、19 条规则。原 HTML 保留供比较；未实现 HTML 执行或原生移动 renderer。
