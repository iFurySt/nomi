# 文稿 AI 原生交互输出

## 目标与边界

文稿 AI 生成可操作的原生交互块，不再把静态画布作为交互请求的回退。沿用现有有界上下文、portable IR、流式新增命令和原子插入；Canvas AI 行为保持不变。暂不扩展任意 JS 或通用仿真运行时。

## 实施

- [x] 文稿独立提示词与输出检查，拒绝静态图和没有控件的假交互。
- [x] 文稿预览 / 插入只接受原生内容块；错误保留原文。
- [x] 测试覆盖真实控件改变结果、保存 / 撤销、拒绝图示回退、取消及上下文。
- [x] 类型、构建、开发版重启和实际 UI 验收；同步说明与 history。

## 风险

现有交互 IR 只支持声明过的组件 / 运算，超范围的要求必须如实提示，不能冒充已实现。开发版无登录时只验证隔离响应，明确不声称在线模型生成已验收。

## 结果

2026-11-07 完成。36 项定向测试、类型检查、Web / Electron 构建及文稿 / Canvas 两项隔离生成回归通过。模拟生成的原生交互块实测滑块改变概率、保存重开、撤销重做；拒绝静态图及不支持响应。Nomi(Dev) 已重启，实际 `/ai` 入口可见；开发版未连接 ChatGPT，未声称在线模型输出验收。未操作正式版或 Transformer 文稿。
