# 本机文稿 MCP

## 目标与范围

用户确认实施前两层：文稿 / 内容块 CRUD、搜索与当前上下文、精确文字编辑、批量事务、定位、附件、引用 / 反向链接、导入导出、持久修改记录与恢复。交互块作为既有类型读写，不增加生成器或画布几何工具。只支持本机桌面，不接家庭 server、云端账号或远程网络。

## 约束与设计

- 与主线程正在开发的交互块保持隔离；不改动其业务文件、不提交其他改动。
- MCP 使用 stdio 适配器，连接显式启用的桌面本机服务；服务仅监听 loopback，使用私有连接文件与随机令牌，拒绝浏览器 Origin。正式与开发 profile 隔离。
- 文稿会话仍为唯一交互写入入口；原子提交携带工作区身份、版本、幂等键，禁止覆盖更晚输入。保存失败不返回成功。
- 历史和回收站存放私有本机 journal；恢复按对象差异验证，保留无关后续修改，冲突不强制覆盖。附件原件保持不可变。
- 外部文件输入输出仅发生在显式导入 / 导出工具；不提供通用文件或代码执行。
