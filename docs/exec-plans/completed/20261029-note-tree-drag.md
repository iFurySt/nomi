# 文稿树拖动移动

## 目标与边界

支持从文稿列表标题按住拖动，行中部移入子页、上下边缘插入同级、列表尾部提升到根级末尾。保留子树、正文与稳定 ID，复用 move_note / 同源存储和撤销；不添加文件夹或外部拖入语义。保留此前尚未提交的标题阅读改动。

## 风险与验证

点击不应误触拖动；按钮 / 菜单不参与拖动。拖动只预览，松开提交一次；移动到自身或后代拒绝，原位操作不写 revision。窗口失焦、Escape、pointercancel 与列表外释放不提交。排序按照完整兄弟集解析，不能被搜索或折叠后的投影误导。触屏继续滚动与菜单移动。

## 验收

类型检查、66 文件 / 392 单测、生产构建、完整 Notes 回归及基础 CI 通过。实际 App 验证拖动、撤销 / 重做、退出重启后的层级与正文保存，并将体验页拖回原父页，保持 358 栏宽。详见同日层级文稿 history 的拖动章节。

## 展开父页边界修正

用户反馈 A 下有 B / C 时，将文稿拖到 A 与 B 之间却落在 C 后。下边缘不能一律解释为整棵子树之后：现在先按可见邻接行识别父子间隙，再使用完整兄弟集确定 before。A 下边缘与 B 上边缘同义，指示线留在该间隙，并按目标层级缩进；折叠、搜索隐藏兄弟、原位与循环保护保持独立验证。

边界修正验证：395 单测、类型 / 构建、完整 Notes 回归通过。真实 App 对 A / B / C 执行 C→A 下边缘得到 A / C / B，撤销恢复原序；窗口已运行最新构建。
