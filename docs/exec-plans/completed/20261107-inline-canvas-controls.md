# 文稿内嵌画布预览与控件

- 统一紧邻正文和画布的上下间距，保留作者主动插入的空段。
- 空画布使用简洁插画与一句空态文字，移除操作说明。
- 悬停 / 键盘焦点显示尺寸手柄和紧凑操作栏；支持编辑、预览缩放 / 适应及当前画布可实现的导出操作。不添加无功能按钮或尚无后端的协作评论。
- 尺寸作为块的可选展示元数据保存，旧文稿继续自动适应；拖动一次作为一笔可撤销修改，不改画布内容坐标。
- 只使用开发版和隔离数据；验证尺寸持久化 / 撤销、正常与空态、窄屏、hover 可达性、文稿打开 / 编辑 / 重启。
- 状态：实现、类型 / 单测 / 独立 Electron 回归和开发版实际验收完成。
- 证据：26 项 core / host 测试；notes-canvas 新增八向缩放、取消、撤销 / 重做、浮栏 hover、缩放 / 下载、上下间距断言。深浅色 / 窄屏截图已检查。
- 下载复用已有离线 ZIP 契约，不提供没有实现的云共享 / 评论。
