# 文稿内画布块

目标：文稿插入独立 Canvas，正文按实际内容边界自适应预览，双击进入现有 Canvas 编辑器，退出继续写作。

范围：复用现有 CanvasWorkspace / 内容 / 形状 / 连线 / 对齐 / AI / 附件及共享保存历史；独立内嵌场景，正文无绘图工具条。旧的本轮试做手绘数据安全迁入场景。

约束：不再维护第二套手绘编辑器。场景使用相同 CanvasDocument IR，但禁止递归嵌入画布；附件仍交给父工作区平台存储。嵌套正文外置、附件导出 / 包导入 / ID 映射同步验证。视口不进入正文，编辑器打开 / 关闭不改内容。

验证：core / 文件包往返、附件与复制；Electron 双击编辑、原有 Canvas 工具、退出自适应、撤销重做、重开、窄屏和离线阅读；完整 Notes / Canvas 回归、生产构建后重启实际 App。

修正：原先误解为内联手绘板，用户已明确要求复用既有 Canvas 并使用双击编辑 / 内容预览模式；改按此方案实施。

状态：已完成。独立场景、原有 Canvas 编辑器、自动预览、文件包 / 资产 / 离线阅读和原型迁入已实现；类型、单测、生产构建、基础 CI、内嵌画布专项、完整 Notes / Canvas 和桌面 smoke 通过。实际 App 已重启并通过双击编辑、文字修改、重开恢复和完成返回预览验收。详见同日 history。
