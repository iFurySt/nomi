# 云同步设置简化

目标：用户能一眼确认是否正在同步，首次使用只需要一个主入口。默认 Nomi 服务，隐藏服务地址与内部云库概念；常规状态显示账号、状态和一个主要操作。

- [x] 收敛未登录 / 已登录未开启 / 同步中 / 暂停 / 异常状态。
- [x] 开启时查询云端：空账号直接创建并同步；已有文稿经明确备份告知后连接，多份才选择。失败可重试，不在进入页面或登录时自动上传。
- [x] 设备、历史、暂停、退出等放次级入口；保留冲突处理。
- [x] 隔离双 Electron 验证真实首次开启与已有云端连接、取消、默认服务和状态，复核深浅色 / 窄屏；构建并重启开发版。
- [x] 更新运行 / UIUX / history 文档。

不改变协议、合并与备份机制，不在实际用户账号上启动同步，不操作正式 App。工作区现有 HTML 交互块设计改动不属于本任务。


完成：类型 / 构建 / 基础 CI 通过。真实 Go / PG + 双隔离 Electron 验证默认 Nomi 地址收起、登录不创建云端文稿、首次一键开启、单份连接取消保留本地、多份明确选择、冲突 / 历史与原有同步回归。截图复核浅色、深色窄屏与连接弹窗；修正隐藏 Electron 截图渲染节流，等待实际绘制后截图。开发版重启确认账号保留且明确显示「尚未开启同步」，未对真实文稿启动上传。
