# 画布交互：选框、吸附与连接

目标：精简选中态，保留八方向调整光标；拖动对象可对齐吸附并显示参考线；从任意内容框引出连接到其他框的线，支持箭头、虚线和后续编辑。完成后实际截图自检。

参考 tldraw bounds / handle snapping 和 Excalidraw 端点绑定。延续 Nomi 平台中立 DSL，不引入第三方编辑器私有文档格式。

- [x] 四角可见锚点，四边透明热区，方向光标强制覆盖 button 默认值；视觉尺寸随缩放保持稳定。
- [x] 世界坐标边缘 / 中心吸附、对齐线；Alt 临时关闭、Shift 锁定轴。
- [x] 连接端口、拖动预览与绑定；曲线 / 折线 / 直线、实线 / 虚线、起终箭头、标签、改接与删除；移动 / 调整尺寸自动跟随。
- [x] 补充矩形 / 椭圆 / 菱形、形状文字、层级与键盘微移等直接相关的基础操作。
- [x] 严格校验、旧文档兼容、原子命令 / undo / redo、删除节点处理连接，保存恢复。
- [x] 核心测试、原生鼠标回归、生产构建，截图检查浅 / 深 / 窄屏并修正；刷新实际 App。
- [x] 同步协议、运行说明、参考来源、发布记录、质量和 history。

“所有画布功能”按可用的基础绘图与关系组织实现，不宣称本轮涵盖手写识别、协作同步或复杂自动避障。新增能力仍服从单机权限与附件边界。
